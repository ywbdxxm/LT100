快捷

第一次用

  1. 板上已经烧录 08_serial_console；如果还是别的例程，先上传 08。
  2. 双击 start-web-console.bat，它会启动本机串口桥并打开页面。
  3. 点「连接串口」；本机桥会自动打开 CP210x，不用手选 COM。桥不可用时才弹出 Web Serial 端口选择。
  4. 看到 PONG 就可以玩：改灯、发文字、看 STAT。没有回复时，先发 PING，或按一下板子的 EN。

运行控制台时串口被本机桥占用；Arduino IDE 的串口监视器要先关掉，烧录前也要先关控制台。页面必须从 localhost 或 HTTPS 打开，不能直接双击 HTML。桥优先，Web Serial 回退需要 Chrome / Edge 89+ 或 Firefox 151+；Safari 只能用桥。
