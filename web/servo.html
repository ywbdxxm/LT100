连接后，这里会告诉你下一步做什么。

raw — · q —

前提：参考姿态 Z 必须在允许行程内；行程最好不跨 0

固件以「包含 Z 的那段弧」为行程，两端谁先标都行。Z 在行程外（收纳位、停靠位、摆错）时，固件会改选补弧——标定仍会保存成功，但可用行程是反的。Z 的位置只能由你保证，固件无法判断。

行程不能跨 0：ST3215 默认角度模式把目标位置当作 0..4095 的绝对角度，按当前值与目标的差值决定方向，不会按标定弧走。跨 0 的目标会让它朝反方向走长路径，越过端点。装配时先接标定工具，手动扫一遍行程看 raw；跨 0 就换舵盘齿/安装位再装。已经装好的机器标出跨 0 时，向导会让你选保留接缝的哪一段（另一段将不可达）。

行程跨 0：选保留哪一段

ST3215 默认角度模式不能跨 0。接缝会把行程切成两段，只能保留一侧；接缝端不是机械端点，手臂会在中途停住，另一侧不可达。

标定原理与 CAL 模式

raw 是舵机内部刻度，单圈 0–4095，转满一圈回到 0；q 是我们定义的角度。标定 = 记零点 + 定正方向 + 划两个端点；保存后才算数，上力后才能动。协议里把两个端点叫 MIN/MAX，它们只是两个槽位；跨 0 的行程默认模式不能执行——ST3215 不会按环形弧走，会朝反方向长路径运动。标出跨 0 时，用 CAL SPLIT 保留接缝一侧（含 Z 的那段），另一段作废。

第一次 CAL REF/DIR/MARK 会进入 CAL 模式；CAL 下 POSE 和 TORQUE ON 都会被拒绝，必须保存或清除才能退出。未保存的编辑掉电丢失。

装配：配 ID → 回中 → 装舵盘

一次只接一颗舵机。按下面三步做，做完一颗断电换下一颗；三颗都配好再一起接。

  1. 配 ID读出当前 ID，设成 肩=1 / 肘=2 / 腕=3，贴好标签。出厂都是 ID1，两颗同时接会抢答。
  2. 回中装舵盘同一颗先「上力」，再点「回中 2048」，把输出轴转到半圈中点后装舵盘/连杆。2048 只是安装参考，不是标定零点。
  3. 卸力扫行程装好后「卸力」，用手把关节从一端扫到另一端看 raw；跨过 4095→0 就换一个舵盘齿/安装位。

raw —在线 0 颗
上力 / 卸力是什么？和“扭矩”什么关系？

上力：打开舵机输出，它会主动顶住当前位置，能抵抗重力。上力前固件会先把目标设为当前位姿，所以不会突然跳。卸力：关掉输出，手能轻松掰动，但舵机仍通电、仍能读 raw；重臂会掉，先扶住。

扭矩/力矩是轴上的“拧劲”。ST3215 标称堵转 30kg·cm、额定 10kg·cm；网页里的「扭矩 开/关」不是调扭矩数值，只是上力/卸力。负载 load 才是舵机当前出力的百分比。

上力不等于锁死：外力超过额定扭矩会推动它，堵转久了会热、会掉压。这也是先标腕、再肘、最后肩的原因。

只接一颗舵机时可用；上力后舵机会保持当前位置，再走目标。

09 串口

>
第一次用 / 安全说明展开看完整步骤
  1. 烧录 09_servo_basic（基于公版 LT100Core），12V 5A 接好并打开，USB-C 接电脑；手扶住手臂。
  2. 双击 start-lt100.bat 打开应用门户，点「标定与检测台」；也可以直接双击 start-servo-console.bat。它们都会启动本机串口桥；桥不可用时才回退 Web Serial。
  3. 点「连接串口」，确认 3/3 在线；0/3 先查 12V、3P 线和 ID 1/2/3。
  4. 选腕 ID3 → 扶住 → 卡片底部「卸力」→ 手移到参考姿态，填 q →「CAL REF」→ 选方向 →「CAL DIR」。
  5. 手移到行程一端 →「标记一端」；再移到另一端 →「标记另一端」；顺序随意，固件取含 Z 的弧为行程；前提是 Z 在允许行程内；行程最好不跨 0，跨了就在向导下方选保留含 Z 的一段；「CAL SAVE」。
  6. 对 ID2、ID1 重复；某个关节标定有效、上力后，就能在「端点测试」里单独试它；三颗都齐了再做整机测试。

标定台运行时会占用串口；Arduino IDE 的串口监视器要先关掉，烧录前也要先关标定台。桥只监听 127.0.0.1，页面必须从 localhost 打开。?mock=1 可模拟界面和命令流，不连硬件。
