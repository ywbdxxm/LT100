## 0. 一句话结论

**第一次做，选「24V + 高显指灯带（COB 或 2835）+ 双路 MOSFET PWM + 铝槽 + 乳白 PC 罩」，8–12W、4000K 或 2700K/5000K 双色温。**

- 想要出光最均匀、几乎看不到颗粒：**COB 灯带**（Ra98，¥6–20/m）
- 想要最便宜、效率最高、最好剪：**2835 灯带**（Ra95–98，¥5.5–25）
- **3030 不是零售 DIY 主流**：淘宝上多为 220V 成品灯板或裸模组，第一次做不选它。

光源部分总成本约 ¥30–60，成功率高，ESP32 直接 LEDC 调光。

不建议第一次做：COB + 恒流（散热和配光难）、WS2812（显色差、频闪）、220V 线性灯板（不安全）。

## 1. 先定目标参数

按 GB/T 9473-2022 AA 级反推（30–40cm 灯高、A4 桌面）：

| 项目 | 目标值 | 说明 |
|---|---|---|
| 中心照度 | ≥500 lx | AA 级；总区域 ≥250 lx |
| 照度均匀度 | ≤3（中心）/ ≤7（总区域） | 越接近 1 越好 |
| 灯具出光 | 600–900 lm | 30–40cm 高度足够，不必上 20W |
| 灯珠功率 | 8–12W | 系统效率按 65–75% 估 |
| 色温 | 4000K，或 2700–5000K 可调 | 读写 4000K 最稳 |
| 显指 | Ra≥95，R9≥50 | 护眼级最低 Ra≥90 且 R9≥50 |
| 频闪 | 波动深度 <3.2%，PWM ≥3 kHz | 驱动决定，不是灯珠决定 |
| 蓝光 | RG0 | 配扩散罩后容易满足 |
| 眩光 | UGR≤19，看不到裸灯珠 | 必须加扩散罩/反光杯 |
| 供电 | 24V SELV | DIY 安全边界 |

> 照度数字来自检测机构和科普文的二手摘要，正式验收以标准原文或检测报告为准。

## 5. 采购时要盯的参数

1. **Ra 和 R9 都要问**。只写 Ra95 不给 R9 的，按 Ra90 看待。
2. **要光谱图**。全光谱/紫光激发的光谱连续性更好；只有蓝光峰 + 黄光峰的别买。
3. **色容差 SDCM≤3**，同批次色温偏差 ≤±50K。
4. **灯带功率按米确认**：常见 8 / 10 / 12 / 15 W/m，别只看「高亮」。
5. **灯带宽度和铝槽匹配**：8mm 灯带配 8mm 槽，10mm 配 10mm。
6. **24V 压降**：超过 2m 要双端供电，否则尾端发暗。
7. **电源留余量**：12W 灯配 24V 1A（24W）即可；15W 以上配 24V 2A。
8. **3C 认证**：电源必须有；灯珠本身没有强制认证。
9. **剪口位置**：灯带只能按标记剪，别随手剪。

## 6. ESP32 接法

```
24V 适配器 ──┬── 灯带/灯板
             └── 5V buck ── ESP32
ESP32 GPIO ── 100Ω ── MOSFET Gate
MOSFET Source ── GND，Drain ── 灯带负极（低边斩波）
```

- **LEDC 硬件 PWM**：3.9 kHz、12 bit；两路分别接暖白/冷白。
- **别用软件定时器翻转 GPIO**：实测会让 PT4115 随中断抖动闪。
- **PWM 直连 DIM 脚**：PT4115 高电平门限 2.5V，3.3V GPIO 直连即可，别加分压压到 2.7V 以下。
- **恒流驱动不能斩输出**：只能调 DIM 脚；CV 灯带才可以低边 MOSFET 斩波。
- **共地**：24V、5V、ESP32 必须共地。
- **天线**：ESP32 放底座，远离金属灯臂和驱动电感；灯头只走 24V + PWM。
- **软启动**：上电先 0% 再缓慢升到目标亮度，避免电源过冲。

## 7. 到货验收

| 项目 | 方法 | 判据 |
|---|---|---|
| 照度 | 照度计，灯头距桌面 35cm | 中心 ≥500 lx，边缘 ≥250 lx |
