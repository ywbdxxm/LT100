## 1. 定位与边界

### 是

- 一个能讲清楚「机械结构 → 舵机 → 总线 → 控制 → 光源」的完整实物
- 每个环节都能测：扭矩、电流、角度、温度、照度、显指、频闪
- 允许拆、允许改、允许失败；坏了能修，改了能对比
- 结构尽量模块化，单个关节/灯头可以独立更换

### 不是

- 不追求量产成本、认证、外观工艺
- 不追求静音、长寿命、工业级可靠性
- 不为了「像产品」而隐藏走线或牺牲可观察性
- 不把「能亮」当成验收；每个功能要有可测量的证据

> 产品思维问「能不能卖」，教具思维问「学生能不能看见、摸到、测到、改到」。

### 1.1 智能硬件教学覆盖

这台教具的价值不在「灯能亮」，而在它把智能硬件的主要分层都摆在桌面上：

| 层 | 能讲什么 | 学生能测到什么 |
|---|---|---|
| **结构** | 三轴悬臂、关节、配重、双支撑 | 重量、重心、关节扭矩 |
| **执行** | 舵机选型、减速比、堵转/额定、保持电流 | 角度-电流曲线、温升 |
| **传感** | 磁编码器、电流、电压、温度、环境光 | 寄存器回读、照度曲线 |
| **控制** | 闭环、软限位、力矩限制、轨迹规划 | 阶跃响应、重复精度、背隙 |
| **通信** | 半双工总线、ID、波特率、协议包 | 总线扫描、抓包 |
| **电源** | 12V 母线、峰值电流、去耦、掉压 | 功耗表、示波器纹波 |
| **光学** | CRI/CCT/照度/频闪/散热 | 照度计、手机慢动作、温度 |
| **交互** | 旋钮、预设、WiFi/BLE、上位机 | 操作演示、遥测数据 |
| **系统** | 集成、安全、失效保护、OTA | 30 分钟连续跑 |

**建议课时**：8 个实验 × 1.5–2 小时，适合中职/本科高年级/创客课程；也可以拆成「结构 + 执行」「控制 + 通信」「光学 + 系统」三个半天模块。

### 1.2 学习目标

做完这套教具，学生应该能：

1. 画出「结构 → 执行 → 传感 → 控制 → 通信 → 电源 → 光学」的系统框图，并指出每一层的输入/输出。
2. 称重、量臂长、算关节扭矩，解释为什么肩部用 30kg 舵机而腕部不用。
3. 通过串行总线读舵机的位置/电流/温度，写一个能设 ID、设限位、读状态的脚本。
4. 用照度计和手机慢动作测光源，解释 CRI、色温、频闪、扩散片各自影响什么。
5. 把「环境光 → 目标照度 → PWM」和「人体感应 → 开关灯」两个闭环跑起来，并做出失效保护。

**考核建议**：实验报告（数据 + 曲线）+ 现场演示（预设姿态/自动调光）+ 故障排查（给一个坏关节或断线，让学生定位）。

## 3. 系统架构

```
              ┌─────────────────────────────┐
              │           灯头              │
              │  10cm 罩 + COB + 扩散片     │
              └──────────────┬──────────────┘
                             │ 腕关节（ST3215）
              ┌──────────────┴──────────────┐
              │          上臂（18cm）        │
              └──────────────┬──────────────┘
                             │ 肘关节（ST3215）
              ┌──────────────┴──────────────┐
              │          下臂（18cm）        │
              └──────────────┬──────────────┘
                             │ 肩关节（ST3215）
              ┌──────────────┴──────────────┐
              │      底座（配重/走线）       │
              │  ESP32 + 12V→5V + 总线转接   │
              └──────────────┬──────────────┘
                             │
                    12V 5A 适配器
```

### 3.1 电气拓扑

```
12V 5A ──┬── 舵机总线（3 只串联，XT/5264-3P）
         ├── LED 恒流/恒压驱动
         └── 5V buck ── ESP32

ESP32 UART TX/RX ── 半双工转接（URT-2 或 74HC126）── 舵机总线
ESP32 GPIO ── 底座旋钮 / 按键
ESP32 I2C ── BH1750 环境光 / 板载温度（可选）
ESP32 GPIO ── 人体感应（可选）
ESP32 WiFi/BLE ── 手机 / PC 上位机（可选）
```

**为什么整灯走 12V**：舵机是 12V 的，LED 也用 12V 灯带/灯板，只需要一个适配器；ESP32 用 5V buck。不要再引入 24V。

**「智能」从哪来**：不是 WiFi 本身，而是「感知 → 决策 → 执行」的闭环。最小可实现的三条：

1. **环境光自适应**：BH1750 读桌面照度，自动调 LED 占空比，维持 500 lx。
2. **人在灯亮 / 人走灯灭**：人体感应 + 延时，教状态机与误触发。
3. **姿态记忆**：舵机编码器读角度，存 4 个预设，一键回到阅读/收纳姿态。

### 3.2 关节与负载

按照片估算（零件未称重）：

| 关节 | 要举的部分 | 静态扭矩（水平） | 动态余量后 | 额定 10kg·cm 是否够 |
|---|---|---|---|---|
| 肩 | 全部臂 + 灯头，约 0.5–0.6kg | 10–14 kg·cm | 15–21 kg·cm | **不够，长期会超** |
| 肘 | 灯头 + 上臂，约 0.3kg | 4–5 kg·cm | 6–8 kg·cm | 够 |
| 腕 | 灯头，约 0.2kg | 1–2 kg·cm | 2–3 kg·cm | 够，余量大 |

**结论**：肩部用 30kg 级是合理的；肘、腕明显过裕。真正该做的是**加弹簧配重**，而不是继续加大舵机。

### 3.3 电源预算

| 状态 | 电流 |
|---|---|
| 3 只待机 | 约 90mA |
| 3 只空载运动 | 约 0.54A |
| 单只堵转 | 2.7A |
| 3 只同时堵转（最坏） | 8.1A |

**电源至少 12V 5A**；12V 2A 会在同时动作时掉压复位。总线入口加 1000µF 电解 + 0.1µF 陶瓷。

> 8.1A 是三只同时堵转的故障态，不需要按它选电源；正常动作 3 只合计约 1.5–2A，5A 留了余量，堵转靠舵机过流保护和保险丝兜底。

## 4. 机械设计要点

### 4.1 关节

- 每个关节目前看起来是**单边支撑**：舵盘在一侧，另一侧没有轴承。
- 后果：输出轴同时承受扭矩和侧向弯矩，容易晃、扫齿、编码器漂移。
- 改进：另一侧加一个 5mm 内孔轴承，做双支撑；舵盘螺丝涂螺纹胶。
- 底座建议加推力轴承，承受悬臂带来的倾覆力矩。

### 4.2 配重

- 目标：让肩关节在常用姿态下接近重力平衡。
- 方案 A：拉簧，从底座连到下臂中部（最像 Anglepoise）。
- 方案 B：下臂尾部加配重块。
- 方案 C：扭簧藏在关节里（最好看，最难做）。
- 验收：在常用姿态下，舵机保持电流从「明显发热」降到「微温」。

### 4.3 走线

- 现在的线在关节外侧，反复弯折会断。
- 走臂内侧的槽，关节处留**服务环**（多留 2–3cm）。
- 用硅胶线（多股细丝），不要在关节处用硬线。
- 灯头线（LED + 测温）与舵机线分开走，避免 PWM/总线干扰。

### 4.4 底座

- 底座要够重：灯头伸到最远时不能翻。
- 估算：整机重心最远约在底座边缘外 10cm，底座配重至少 1kg。
- 底部加硅胶脚垫。

## 5. 控制与固件

### 5.1 总线

- 3 只舵机 ID 设为 1/2/3，统一 1Mbps。
- ESP32 用 UART + 半双工方向控制；建议先用 URT-2 调试板在 PC 上验证 ID 和方向。
- 上电先读位置、电压、温度；任何一只不在预期范围就进入安全姿态。

### 5.2 固件功能（最小集）

1. **绝对角度控制**：磁编码器，上电不需要回零。
2. **软限位**：每个关节设 min/max，防止撞灯罩/底座。
3. **力矩限制**：堵转/碰撞时降力矩，而不是硬顶。
4. **速度/加速度**：梯形或 S 曲线，避免灯头甩动。
5. **预设姿态**：阅读 / 写作 / 氛围 / 收纳。
6. **状态回读**：位置、电流、温度，串口输出。
7. **失联保护**：总线断线时缓慢卸力，不突然掉落。
8. **环境光闭环**（加 BH1750 后）：目标照度 → PWM 占空比，带死区和斜率限制。
9. **人体感应状态机**（加传感器后）：无人延时关灯，有人渐亮，避免频繁开关。
10. **WiFi/BLE 遥测**（可选）：上报角度、电流、温度、照度；接收预设和 OTA。教「设备上云」之前先把本地闭环做稳。

### 5.3 安全

- 30kg·cm 的关节夹手很疼；固件限力矩 + 机械留缝。
- 灯头温度：COB 满功率 30 分钟后外壳 <55°C。
- 12V 总线加保险丝（5A）或电子熔断；保险丝是防短路，不是防堵转。

## 6. 光源与光学

### 6.1 现状

- 灯罩内径 10cm，锥形，**内外都是橙色**，内部没有反射层。
- LED 模块未安装；背面只有 4 颗螺丝。

### 6.2 关键问题：橙色内壁

橙色内壁会把光染橙，Ra98 也救不回来。必须二选一：

1. 内壁喷**哑光白**（耐温 120°C 以上）。
2. 加一层**白色 PC 或镜面铝反射内衬**（可拆卸，方便对比实验）。

这本身就是一个很好的教学实验：同一颗 COB，橙色 vs 白色内壁，测色温和显指。

### 6.3 推荐光源

10cm 圆罩不适合条形灯带，推荐：

| 方案 | 配置 | 说明 |
|---|---|---|
| **A（推荐）** | 10–12W COB，Ra≥95，3000/4000K，12V 恒压或恒流 | 发光面 Ø10–15mm，配 60° 反光杯 |
| B | 2835 环形灯板，Ø70–80mm，24–30 颗 | 中心容易暗，必须加扩散片 |
| C | COB + 10cm 乳白 PC 扩散片 | 最均匀，损失约 20–30% 光 |

**散热**：10W COB 要有铝基板 + 金属散热片，不能只靠橙色塑料罩。建议在罩背加一块 2mm 铝板，把热引到罩外。

### 6.4 目标参数

- 桌面中心照度 ≥500 lx（AA 级）
- 色温 4000K（或 2700–5000K 可调）
- Ra≥95，R9≥50
- 频闪：PWM ≥3kHz 或恒流
- 灯罩内壁白色，UGR≤19

> 具体灯珠/灯带选型见 [light-source-selection.md](light-source-selection.md) 与 [led-shortlist-2835-cob.md](led-shortlist-2835-cob.md)。注意：那两份文档是按「条形灯头」写的，现在灯头改成 10cm 圆罩，**优先看 COB 方案**。

## 7. 教学模块

建议 8 个实验，每个 1.5–2 小时。

> **只有 4 小时**：重点是 AI agent 写代码 → 走 [4h-ai-agent-course.md](4h-ai-agent-course.md)；重点是学生动手装配 → 走 [4h-course.md](4h-course.md)。两版都用 [quick-build-bom.md](quick-build-bom.md) 的现成模块。本文的 8 个实验用于完整学期或课后扩展。

### 实验 0：系统认识与拆装

- 认出各层：结构、舵机、总线、电源、控制、光源。
- 画一张自己的系统框图，标出「输入/输出/供电/通信」。
- 拆一个关节，观察舵盘、轴承、限位；装回去，确认零位。
- 产出：一张手绘框图 + 一份拆装记录。
- 目的：先建立「整机」概念，再进单点实验。

### 实验 1：静力学与配重

- 称灯头、上臂、下臂重量，量重心位置。
- 计算三个关节的静态扭矩。
- 用舵机回读电流，对比「无配重 / 有弹簧」。
- 产出：一张「姿态 vs 肩关节电流」曲线。
- 结论：为什么 30kg 舵机在肩部不算夸张，在腕部却是浪费。

### 实验 2：三轴运动学

- 量臂长，建立 3R 平面臂模型。
- 用舵机角度计算灯头位置；在纸上画工作空间。
- 验证：给一组角度，卷尺量实际位置，算误差。
- 讨论：奇异点、可达范围、灯头姿态。

### 实验 3：串行总线

- 用 URT-2 或 ESP32 扫描 ID。
- 读写位置、速度、力矩、温度、电压寄存器。
- 故意设错 ID/波特率，观察总线表现。
- 产出：一页协议笔记 + 一个能读温度的脚本。

### 实验 4：闭环与重复精度

- 命令阶跃角度，记录实际角度曲线。
- 测重复定位精度和背隙（正反方向各 10 次）。
- 调加速度/力矩限制，观察超调和抖动。
- 讨论：为什么「舵机内部闭环」不等于「系统精度」。

### 实验 5：光源与光学

- 测照度（中心/边缘）、色温、显指（有条件）。
- 手机慢动作拍频闪；有光电二极管的话看波形。
- 对比：橙色内壁 vs 白色内衬。
- 对比：裸 COB vs 加扩散片。
- 产出：一张「方案 vs 照度/均匀度/色温」表。

### 实验 6：系统集成

- 写 4 个预设姿态，带平滑过渡。
- 加软限位、力矩限制、失联保护。
- 测整机功耗：待机 / 运动 / 照明。
- 连续跑 30 分钟，记录舵机温度和灯头温度。
- 产出：一份「整机测试报告」。

### 实验 7：联网与交互（可选）

- ESP32 开 WiFi/BLE，手机或 PC 连上，读角度/电流/温度/照度。
- 下发一个预设姿态，测「点击 → 动作」的延迟。
- 故意断网/断电，观察重连和失效保护。
- 讨论：本地闭环 vs 云端控制、配网方式、凭据怎么存。
- 产出：一个能看遥测、能下发预设的最小上位机。

> 顺序建议：先做 0–6，把本地闭环和光源做稳；联网是加分项，不是第一天的内容。

## 9. 待办与风险

### 待办

1. 称重：灯头、上臂、下臂、底座；实测三个关节的保持电流。
2. 确认底座旋钮的功能（电位器/编码器/开关）。
3. 决定底座是手动转向还是加第四个舵机。
4. 灯罩内壁做白色处理，测色温差异。
5. 装 COB + 扩散片，测照度和温升。
6. 关节加对侧轴承；底座加推力轴承。
7. 走线改到臂内，关节留服务环。
8. 电源换 12V 5A，加保险丝和电容。
9. 固件：软限位、力矩限制、4 个预设、温度回读。
10. 加 BH1750 环境光，做「目标照度 → 自动调光」闭环。
11. 加人体感应，做「人走灯灭」状态机。
12. 选 ESP32 型号（建议 S3，带 WiFi/BLE），做遥测和预设下发。

### 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 肩关节长期超额定扭矩 | 发热、热保护、寿命下降 | 加弹簧配重；限制水平姿态停留 |
| 橙色内壁 | 色温偏橙、显指下降 | 喷白/加白色内衬 |
| 单边支撑 | 关节晃动、扫齿 | 加对侧轴承 |
| 12V 2A 电源 | 同时动作掉压复位 | 换 5A，加电容 |
| 外露线束 | 关节处断线 | 走臂内 + 硅胶线 + 服务环 |
| 灯头散热 | COB 光衰、塑料变形 | 铝板导热 + 外壳散热 |
| 夹手 | 30kg·cm 力矩 | 固件限力矩 + 机械留缝 |
| 环境光传感器被灯罩直射 | 自动调光振荡/跑飞 | 传感器朝桌面、加遮光罩、限制调节斜率 |
| WiFi 天线靠近金属臂/舵机线 | 信号差、断连 | ESP32 放底座、天线朝外、远离功率线 |
