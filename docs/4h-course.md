# LT100 四小时课程设计（硬件装配版）

- 日期：2026-11-17
- 课程名：**4 小时做出一个会自己调光的机械臂台灯**
- 如果课程重点是「AI agent 写代码、硬件做验收」，走 [4h-ai-agent-course.md](4h-ai-agent-course.md)
- 对象：中职/本科高年级/创客，2–3 人一个工位
- 规模：6 个工位（12–18 人），1 名主讲 + 1 名助教
- 前置：不需要焊接、不需要写代码；会用电烙铁不是必需

---

## 1. 课程目标

4 小时结束时，每个工位必须能演示：

1. **三个姿态预设**：阅读 / 写作 / 收纳，一键平滑切换。
2. **环境光自动调光**：遮住传感器灯变亮，照亮传感器灯变暗，目标 500 lx。
3. **实时读数**：串口能看到三个关节的角度、电流、温度和当前照度。
4. **一次故障定位**：教师注入一个故障，学生在 5 分钟内找到并修复。

不追求：WiFi/云端、PID 调参、PCB 设计、机械结构从零搭建、Ra95 显指。

> **4 小时不写代码**：固件预烧，学生用串口 CLI 配置行为。写代码（读传感器、写状态机）放第二次课；这次先把「接线 → 校准 → 演示」跑通。

---

## 2. 课前准备（教师，约 2 小时）

### 2.1 机械

- [ ] 机械臂预装好，三个关节活动顺畅，螺丝紧固。
- [ ] 用 URT-2 把三个舵机 ID 设为 **1（肩）/ 2（肘）/ 3（腕）**，方向确认。
- [ ] 记录三个关节的**安全姿态**（不会撞灯罩/底座），写进固件默认值。
- [ ] 灯罩内壁贴好白色 PET 反光膜（或喷哑光白），确认看不到橙色内壁。
- [ ] 按 Ø100mm 切好乳白亚克力扩散片；按灯罩口做 3 个卡扣或双面胶位。
- [ ] COB 用导热硅脂贴在 100×100×2mm 铝板上，引线留 15cm。
- [ ] 扩散片与 COB 间距 ≥15mm，避免热点。

### 2.2 电气

- [ ] 每个工位一套模块，按「工位料盒」分装并贴标签。
- [ ] ESP32 预烧固件（见第 6 节），串口 CLI 自测通过。
- [ ] TTL Adapter 与 8P Hub 的线序确认，舵机线编号 1/2/3。
- [ ] 12V 5A 适配器逐个测电压；buck 逐个调到 5.0V 并锁死。
- [ ] 准备 1 个「黄金工位」：完整可演示，课上做对照。

### 2.3 教室

- [ ] 6 张桌子，每张 1.2m 宽，靠墙留走线空间。
- [ ] 每 2 个工位 1 个万用表；讲台 1 个。
- [ ] 插排够用；12V 适配器不要共用一条劣质插排。
- [ ] 打印「接线图」A3 每工位 1 张、「测量表」每人 1 张。

## 5. 分块讲解要点

### 5.1 系统认知（20 分钟）

在黑板上画五层，边指实物边说：

```
结构 → 执行（舵机） → 传感（编码器/光照） → 控制（ESP32） → 通信（总线）
                                      ↘ 电源（12V/5V） → 光学（COB/扩散）
```

只讲三个问题：

1. 电从哪来，到哪去？（12V → 舵机/LED；5V → ESP32）
2. 指令怎么走？（串口 → TTL Adapter → 总线 → 舵机 ID）
3. 反馈怎么回来？（编码器/电流/温度/光照 → 串口）

### 5.2 机械（40 分钟）

- COB 贴铝板：导热硅脂薄薄一层，四角螺丝固定。
- 反光膜：从灯罩口往里贴，尽量平整；有褶皱就用吹风机低温吹。
- 扩散片：离 COB ≥15mm；用双面胶或 3 个卡扣，别用热熔胶（会掉）。
- 走线：舵机线沿臂内侧，关节处留 2–3cm 服务环；用扎带固定，别拉紧。
- 检查：手转三个关节到底，线不能被夹、不能被拉直。

### 5.3 电气（45 分钟）

按顺序接，**每接完一段用万用表量一次**：

1. 12V 适配器 → DC5521 免焊端子 → 12V 母线（红/黑）。
2. 12V 母线 → 8P Hub 电源；Hub 三个口 → 三个舵机。
3. 12V 母线 → buck IN；buck OUT 调到 5.0V → ESP32 5V/GND。
4. ESP32 UART2（TX/RX/GND）→ TTL Adapter；Adapter → Hub 信号。
5. ESP32 3V3/GND → BH1750；GPIO → SDA/SCL。
6. ESP32 3V3/GND → KY-040；GPIO → CLK/DT/SW。
7. 12V+ → COB+；COB- → MOS 漏极；MOS 源极 → GND；栅极 → GPIO（100Ω + 10k 下拉）。

**三条红线**：

- 上电前必须量 12V 和 5V，确认没有反接。
- 舵机线不要热插拔（带电插拔可能烧总线）。
- 共地：12V 负极、5V 负极、ESP32 GND、MOS 源极必须连在一起。

### 5.4 上电与烧录（30 分钟）

1. 先只接 12V 和 buck，量 12V/5V。
2. 接 ESP32，USB 接电脑，确认串口。
3. 烧录预编译固件（或确认已烧好）。
4. 打开串口 115200，输入 `help`。
5. 输入 `scan`，确认 1/2/3 都在。
6. 输入 `pos`，读三个角度；手轻推关节，角度应变化。

### 5.5 校准（35 分钟）

- 用 `move <id> <deg>` 逐个关节找安全范围。
- `limits <id> <min> <max>` 写入软限位。
- 摆三个姿态，`preset 1/2/3` 保存。
- `go 1/2/3` 回放；速度太快就调 `speed`。
- `auto 1 500` 开自动调光；用手遮传感器，看 LED 变化。
- `save` 写入 NVS；断电重启，确认预设还在。

### 5.6 故障排查（30 分钟）

教师给每个工位注入一个故障（见第 8 节），学生按「电源 → 通信 → 执行 → 传感」顺序排查。

## 6. 固件 CLI（教师预烧）

串口 115200，命令一行一条：

| 命令 | 作用 |
|---|---|
| `help` | 列出命令 |
| `scan` | 扫描 ID 1–10，打印在线舵机 |
| `pos` | 打印三个舵机的位置/电压/温度/负载 |
| `move <id> <deg>` | 单关节移动到绝对角度 |
| `speed <id> <0-100>` | 设置速度 |
| `limits <id> <min> <max>` | 设置软限位 |
| `preset <n> <a1> <a2> <a3>` | 保存第 n 个预设 |
| `go <n>` | 平滑移动到第 n 个预设 |
| `led <0-100>` | 设置 LED 亮度 |
| `lux` | 读 BH1750，打印 lux |
| `auto <0\|1> [target]` | 开关自动调光，目标 lux |
| `temp` | 打印舵机温度 |
| `save` | 保存限位/预设/目标到 NVS |
| `reset` | 恢复默认 |

### 6.1 引脚分配（建议）

| 功能 | ESP32-S3 | 说明 |
|---|---|---|
| 舵机总线 TX | GPIO17 | UART2 TX → TTL Adapter RX |
| 舵机总线 RX | GPIO18 | UART2 RX ← TTL Adapter TX（注意电平） |
| BH1750 SDA | GPIO8 | I2C |
| BH1750 SCL | GPIO9 | I2C |
| LED PWM | GPIO4 | LEDC 5kHz / 12bit → MOS 栅极 |
| 编码器 CLK | GPIO5 | 中断 |
| 编码器 DT | GPIO6 | 中断 |
| 编码器 SW | GPIO7 | 上拉输入 |
| 12V 检测（可选） | GPIO1 | 分压 1/5，做掉压告警（避开 GPIO3 等 strapping 脚） |

### 6.2 库

- **SCServo**（Feetech 官方 Arduino 库，支持 ST/SC 系列）
- **BH1750**（Christopher Laws）
- **ESP32Encoder**（或自己写正交解码 ISR）
- Arduino ESP32 core 3.x（LEDC API）

**固件要求**：

- 上电不自动动，先打印状态，等命令。
- `move`/`go` 必须检查软限位。
- 自动调光每 500ms 一次，带斜率限制（比如每次最多变 5%），避免振荡。
- 任一舵机离线，打印 `ERR servo <id> offline`，其余关节继续工作。
- 看门狗：串口 30 秒无命令不动作，但不复位。

## 8. 故障注入库

每个工位随机一个，教师提前记好：

| 故障 | 注入方法 | 期望排查路径 |
|---|---|---|
| A. 舵机 2 不响应 | 拔掉 2 号舵机线，或把 ID 改成 9 | `scan` 少一个 → 查线/查 ID |
| B. LED 常亮不可调 | MOS 栅极短到 12V，或换错 GPIO | 万用表量栅极 → 查 PWM 引脚 |
| C. 自动调光振荡 | 把 BH1750 对着灯罩 | `lux` 读数异常 → 遮光/加斜率 |
| D. 一动就复位 | 换 12V 2A 电源 | 量 12V 跌到多少 → 换 5A/加电容 |
| E. 灯头下垂 | 把力矩限制设到 10% | `pos` 位置对但保持不住 → 调力矩/配重 |

## 10. 常见时间坑与兜底

| 坑 | 预防 | 兜底 |
|---|---|---|
| 串口驱动装不上 | 课前装好 CH340/CP210x | 换备用 ESP32/数据线 |
| 舵机 ID 乱 | 课前统一设好 | 用 URT-2 现场改，或换备用舵机 |
| 12V 反接 | 端子用红黑、贴标签 | 烧了 buck 就换，别修 |
| 扩散片尺寸不对 | 课前按灯罩口切好 | 用白色卡纸临时替代 |
| 自动调光振荡 | 固件带斜率限制 | 先关 auto，用 `led` 手动演示 |
| 进度落后 | 硬检查点 | 跳过故障排查，教师演示，课后补 |

**最低可交付演示**：`go 1/2/3` 三个预设 + `led 0/50/100` 手动调光。自动调光做不出来不算失败，但要记录。
