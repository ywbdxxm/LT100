# LT100 四小时课（硬件装配线 / AI Agent 线）

- 日期：2026-11-17 初稿，2026-11-18 定稿，2026-11-20 合并为一份课程文档
- 对象：中职 / 本科高年级 / 创客，2–3 人一个工位
- 规模：6 个工位（12–18 人），1 名主讲 + 1 名助教
- 硬件：微雪 Servo Driver with ESP32 + 3×ST3215 + 24 灯 WS2812 环（板载 5V 限 40%）

**两条线选一条；有 8 小时就上午 A、下午 B。**

> **2026-11-21 口径**：安全/标定/公版接口以 [common-platform.md](../design/common-platform.md) 为准。当前结构 **没有机械硬限位、没有弹簧/配重、yaw 只能手动**；软件标定/限位是唯一保护。本文的 CLI/软限位是课程摘要，不是另一套协议。

| 线 | 重点 | 适合 |
|---|---|---|
| **A 硬件装配线**（§5、§6、§11） | 接线、校准、排障、测量 | 学生动手装硬件，不写代码 |
| **B AI Agent 线**（§7–§10） | 写规格 → AI 改码 → 硬件验收 | 工位已预装，学生用 AI 写功能 |

两线共用：课前准备（§2）、硬件契约（§3）、固件 CLI（§4）、故障注入（§11）、兜底（§13）。

## 1. 课程目标

**A 线**，4 小时后每个工位能演示：

1. 三个姿态预设（阅读 / 写作 / 收纳），一键平滑切换。
2. 灯环颜色/亮度：暖白、冷白、红/绿/蓝、呼吸/彩虹，串口可切。
3. 实时读数：三个关节的角度、电流、温度、输入电压。
4. 一次故障定位：教师注入故障，学生 5 分钟内找到并修复。

**B 线**，4 小时后学生应该能：

1. 写一份 AI 能执行的硬件契约（引脚、ID、库、限位、灯环像素、安全规则）。
2. 让 AI 完成「改代码 → 编译 → 读串口」的闭环；**烧录这一步由人执行**（按住 `KEY_FLASH` + IDE 上传），agent 不代烧。
3. 用硬件证据验收 AI 的输出，而不是「它说完成了」。
4. 识别 AI 在嵌入式里的五类常见错误：引脚冲突、阻塞延时、越界、未处理舵机离线、灯环像素/颜色错。
5. 用测试脚本驱动 AI 迭代。

两线都不追求：从零搭机械、手写驱动、PID 调参、云端后端、量产工艺、COB/照度/显指。

## 2. 课前准备（教师，约 2 小时）

### 2.1 机械

- [ ] 机械臂预装好，三个关节活动顺畅，螺丝紧固。
- [ ] 用 URT-2 或板载 Web UI 把三个舵机 ID 设为 **1（肩）/ 2（肘）/ 3（腕）**，方向确认。
- [ ] 记录三个关节的**安全姿态**（不撞灯罩/底座），写进固件默认值。
- [ ] 灯罩内壁贴白色 PET 反光膜（选装；不贴也能用，颜色偏暖）。
- [ ] 按 Ø100mm 切好乳白亚克力扩散片，按灯罩口做 3 个卡扣或双面胶位。
- [ ] 24 灯 WS2812 环（72mm 外径）用双面胶/尼龙柱固定在灯罩内；扩散片离灯环 **10–15mm**。
- [ ] 灯环线沿臂内侧走，关节处留 2–3cm 服务环。

### 2.2 电气与固件

- [ ] 每个工位一套模块，按「工位料盒」分装并贴标签。
- [ ] 主控板预烧固件（§4），串口 CLI 自测通过。
- [ ] 12V 5A 适配器逐个测电压，直接插主控板 DC5.5×2.1。
- [ ] 教师课前做好 1.25mm 3P 转杜邦 1P×3 线（6+1 根）：杜邦母头插灯环 SM 母座，不用焊。
- [ ] 板子手册写 PH1.25，实际是 **1.25mm 3P**；买 MX1.25/1.27 转杜邦，别买 PH2.0。
- [ ] 灯环经转接线从主控板 5V 取电：5V→5V、GND→GND、OUT→DIN（线色：红 5V / 白 GND / 绿 DIN）。
- [ ] 固件已写入 40% 亮度硬上限；上电前确认没有全白预设。
- [ ] 留 1 个「黄金工位」：完整可演示，课上做对照。
- [ ] 备用：主控板 ×1、舵机 ×1、灯环 ×1、3P 转接线 ×2、5264 线 ×4、保险丝 ×4。

### 2.3 教室与料盒

- [ ] 6 张桌子，每张 1.2m 宽，靠墙留走线空间。
- [ ] 每 2 个工位 1 个万用表；讲台 1 个。
- [ ] 插排够用；12V 适配器不要接劣质插排。
- [ ] 打印「接线图」A3 每工位 1 张、「测量表」每人 1 张。
- [ ] 料盒（按 [build-bom.md](../build/bom.md) 准备）另加：标签纸+记号笔、小十字螺丝刀、剪线钳、剥线钳、
      绝缘胶带/热缩管、备用 5264 线 ×2、备用保险丝 ×2、备用 24 灯环 ×1、备用 3P 转接线 ×2。

### 2.4 软件与 Agent（仅 B 线）

- [ ] **Arduino IDE 2.x**：学生看代码、看串口；**烧录由人用 IDE 手动配合**（按住 `KEY_FLASH` 再点上传，见 [flashing.md](flashing.md)）。
- [ ] **arduino-cli**：agent 编译、读串口、跑测试脚本；**不承担课堂烧录**；与 IDE 共用同一套 core 和 libraries。
- [ ] ESP32 core 4.0.0 + 库（**SCServo**、**Adafruit_NeoPixel**）。装机与离线包见 [arduino-env.md](arduino-env.md)。
- [ ] 串口驱动（CH340/CP210x）装好，端口号固定。
- [ ] Python 3 + `pyserial`（测试脚本用）。
- [ ] AI agent 可用（Claude Code / Codex / Cursor），并授予：读工程、`arduino-cli compile`、
      `arduino-cli upload -p COMx`、`python tools/monitor.py COMx 115200 5`。
- [ ] 每个工位一个 `station.env` 写明端口号，避免烧错板。
- [ ] 每工位能登录 agent（账号/API key），跑通一次「读文件 → 改文件」。
- [ ] 网络稳定；离线兜底：教师预生成 2–3 个功能的 diff/固件。
- [ ] **预批准命令**：`arduino-cli compile/upload`、`python tools/monitor.py`、`python tools/test_*.py`。
      Claude Code 写在 `.claude/settings.json` 的 `permissions.allow`；Codex 写在 `AGENTS.md` 并配 approval policy；
      Cursor 开启 Agent 模式允许终端命令。
- [ ] 给每个工位设 token/费用上限；禁用 agent 的「自动提交/自动推送」。

### 2.5 项目模板与工具链（仅 B 线）

```text
lt100-station/
├── AGENTS.md              # AI 必须遵守的规则（见 §8.1）
├── hardware.md            # 硬件契约（§3）
├── sketch.yaml            # CLI 的 FQBN/端口；IDE 选同一组
├── lt100_station.ino      # 基线固件（已跑通）
├── tools/
│   ├── flash.ps1          # 编译 + 烧录
│   ├── monitor.py         # 读串口 N 秒并打印
│   └── test_*.py          # 验收脚本
└── README.md              # 本工位怎么跑
```

`sketch.yaml` 示例：

```yaml
default_fqbn: esp32:esp32:esp32
default_port: COMx  # 换成自己机器上的端口
```

**IDE 与 CLI 共存的五条规则**：

0. **烧录只由人做**：课堂烧录一律「按住 `KEY_FLASH` + IDE 上传」；agent 只做编译、读串口、排障，不代烧。
1. **一个端口**：IDE 串口监视器打开时 agent 读不到串口；约定「烧录前关监视器」，或 agent 统一用 `monitor.py`。
2. **一个 FQBN**：CLI 从 `sketch.yaml` 读；IDE 选 `ESP32 Dev Module`、上传 921600。
3. **一个写者**：agent 改 `.ino` 时学生不要在 IDE 里同时编辑；IDE 只用于看/烧/看串口。
4. **一台母机**：装好 IDE、core、库、驱动、Python 后整体复制到 6 台，别让 6 个工位同时下 1GB。

**为什么不用 PlatformIO**：PlatformIO 更好，但 4 小时第一次课太重（VS Code + 插件 + 平台包）。
课程稳定、要接 CI、要多板并行、要锁库版本时再迁移。

## 3. 硬件契约（hardware.md 的核心）

AI 最容易犯的错是「随手改引脚」「删掉限位」「用阻塞延时」「灯环像素数不对」。契约就是划红线。

| 项目 | 值 | 约束 |
|---|---|---|
| 舵机总线 | 板内 UART1，GPIO18=RX，GPIO19=TX，1Mbps | 不许改波特率/引脚 |
| 舵机 ID | 1=肩，2=肘，3=腕 | 不许重编号 |
| 软限位 | 肩 -20~80°，肘 0~110°，腕 -30~60° | 不许删/放宽 |
| OLED | I2C，GPIO21=SDA，GPIO22=SCL，0x3C | 板载，不许改 |
| WS2812 | GPIO23；26 颗（2 板载 + 24 灯环）；GRB，800kHz | 灯环索引以 `test_led` 实测为准（默认从 2 开始）；全局亮度 ≤40%（102/255） |
| 输入电压 | 板载 ADC，OLED 显示 | 6–12V，不许超 12V |
| 扩展 IO | **没有排针**；只有 1.25mm 3P 的 WS2812 扩展（标 PH1.25） | 不要计划接 BH1750/编码器/COB |
| 安全 | 上电不动、软限位、力矩限制、离线降级 | **任何一条都不许删** |

**给 AI 的一句话**：引脚、ID、限位、灯环像素是硬约束；你可以加功能，但不能改这些。

## 4. 固件 CLI（教师预烧）

串口 115200，命令一行一条。**08 和 09 是两套固件，不合并**：

- **08 串口控制台**：只做灯、OLED 和板子状态，不接舵机。
  `HELP` / `PING` / `INFO` / `STAT` / `MODE SOLID|RAINBOW|BREATHE|OFF` /
  `COLOR RRGGBB` / `BRIGHT 0..40` / `TEXT <ascii>` / `CLEAR` / `STREAM 0|1`。
- **09 舵机 + 公版标定台**：走 `LT100P/1`，完整命令见
  [common-platform.md §8](../design/common-platform.md)：
  `HELLO` / `STATE` / `STREAM` / `TORQUE` / `CAL ...` / `LIMITS` /
  `POSE seq= q= speed= acc=` / `STOP` / `ESTOP` / `CLEAR`。

`scan`、`pos`、`move`、`preset`、`go`、`led` 这些旧课命令**当前固件没有**；
预设和灯环控制属于后续整机 app，不要按旧讲义演示。

**库**：SCServo（Feetech 官方）、Adafruit_NeoPixel、Adafruit SSD1306/GFX、
U8g2、Arduino ESP32 core 4.0.0；09 另需公版 `LT100Core` / `LT100Board`。

**固件要求**：

- 上电不自动动、不自动上力，先打印状态，等命令。
- `POSE` 必须检查标定完整与软限位；越界直接拒绝，不静默钳位。
- 任一舵机离线进入 `FAULT`，停止自动运动；恢复后要 `CLEAR`。
- 失联 300ms：停止接受新 `POSE`，保持最后目标，不自动卸力。
- 灯环全局亮度硬上限 40%（102/255）；不提供全白命令，不允许串口/预设绕过。

### 5.1 A 线讲解要点

**系统认知（20 分钟）**，黑板上画五层，边指实物边说：

```text
结构 → 执行（舵机） → 控制（ESP32） → 通信（总线） → 灯光（WS2812）
                                  ↘ 电源（12V/5V）
```

只讲三个问题：电从哪来到哪去；指令怎么走；灯光怎么走（串口 → GPIO23 → DIN → 每颗灯珠）。

**机械与灯环（30 分钟）**：灯环 24 灯 72/54mm 放进 10cm 罩；扩散片 Ø100×2mm、离灯环 10–15mm；
反光膜从罩口往里贴，有褶皱用吹风机低温吹；走线沿臂内侧、关节留 2–3cm 服务环；
检查：手转三个关节到底，线不能被夹、不能被拉直。

**装舵盘前先查行程（关键）**：机械臂装死后先别急着锁舵盘。接好 12V、USB 和 09 标定台，
`TORQUE <id> OFF` 后用手把关节从一端扫到另一端，看网页上的 raw：

- 整段 raw **不经过 4095→0**：正常，继续装、锁舵盘、按 §5.1 标定。
- raw **跨过 0**：在装配阶段就换一个舵盘齿/转舵机安装位，把 0 点移出机械行程，再锁舵盘。
  这一步省掉，后面标定只能用 `CAL SPLIT` 截掉一段行程（应急，不是等价替代）。
- 记录每个关节扫到的 raw 范围，填进 §6 测量表；它是后面标定端点时的参考。
- 装舵盘前可以用「装配」页的**回中 / 安装定位**：只接一颗、先上力，再点「回中 2048」或输入目标 raw，把舵机转到安装角；这时还没有标定，raw 移动没有 safe 保护，速度用 5°/s。已有标定记录的关节要先 `CAL CLEAR` 才能用。

**电气（40 分钟）**，按顺序接，每接完一段用万用表量一次：

1. 12V 5A 适配器 → 主控板 DC5.5×2.1。
2. 主控板 3P 总线口 → 3 只 ST3215 串接（肩单独一口，肘+腕另一口）。
3. 1.25mm 3P 转杜邦 → 灯环 SM 头：5V→5V、GND→GND、OUT→DIN。
4. 主控板 USB-C → 电脑。

**三条红线**：上电前量 12V；舵机线不许热插拔；**灯环 40% 上限不许改、不许做全白**（24 灯全白 1.44A 超板载 5V）。

**上电与烧录（30 分钟）**：先只接 12V 量电压 → 断电插灯环 → 上电 → USB-C 接电脑 → 串口 115200 →
烧 **08**：`HELP` → `MODE RAINBOW` / `COLOR FF6600` / `BRIGHT 20` → `STAT` 看状态；
烧 **09**：`STATE` 确认 `online=7`，手推关节看 raw 变化。

**校准（35 分钟）**：先扶住手臂 → 网页标定台（`start-servo-console.bat`）或串口：
`TORQUE <id> OFF` → `CAL REF/DIR/MARK` → `CAL SAVE` → 三关节都有效后 `TORQUE all ON` →
低速端点测试 → 断电重启确认标定还在。没有机械硬限位，软件限位是唯一保护。

**故障排查（30 分钟）**：每工位注入一个故障（§11），按「电源 → 通信 → 执行 → 灯光」顺序排查。

### 8.1 Agent 规则（AGENTS.md / CLAUDE.md）

```markdown
# 工作规则
```

## 9. B 线：测试脚本（AI 的裁判）

| 脚本 | 做什么 | 通过标准 |
|---|---|---|
| `test_link.py` | 发 `HELLO` / `STATE` | 回协议版本；三只在线时 `online=7` |
| `test_limits.py` | 发越界 `POSE` | 回 `ERR 10`，舵机不动、不堵转 |
| `test_cal.py` | `CAL REF/DIR/MARK` + `CAL SAVE` | `CAL STATUS` 三关节 `valid=1`；重启后仍有效 |
| `test_smooth.py` | 20Hz 连续 `POSE` | 无突然甩动；`speed` 不超过 52°/s |
| `test_led.py` | `MODE`/`COLOR`/`BRIGHT` / 逐颗点亮 | 26 颗顺序正确、不串色；亮度 ≤40% |
| `test_offline.py` | 拔舵机 2，发 `STATE` | `online` 缺对应位、模式进 `FAULT`；其余关节仍可读 |
| `test_estop.py` | `ESTOP` → `CLEAR` | 急停锁存；`CLEAR` 后不自动运动 |

> AI 最怕「没有反馈」。测试脚本就是把硬件现象变成可读的 PASS/FAIL。

## 10. AI 常见错误（B 线教师重点讲）

| 错误 | 现象 | 怎么发现 |
|---|---|---|
| 引脚冲突 | 灯环颜色乱/舵机不动 | 对照 hardware.md；GPIO23 被占用 |
| 灯环像素数/偏移错 | 第一颗不亮、颜色错位 | `test_led` 逐颗点亮；2 板载 + 24 环 = 26 |
| 颜色顺序错 | 红变绿、蓝变红 | WS2812B 是 GRB；`NEO_GRB` |
| 灯环供电错 | 板子重启/灯环闪烁 | 去掉 40% 限幅全白 1.44A + 板子 0.2A，超板载 5V |
| 阻塞延时 | 按键/串口卡顿，动作抖动 | 代码审查 + 响应测试 |
| 越界 | 舵机撞灯罩/堵转发热 | 越界 `POSE` 应回 `ERR 10`，不能靠机械硬顶 |
| 舵机离线未处理 | 拔掉舵机后整机卡死 | 拔线测试 |
| 串口占用 | 烧录失败/监视器打不开 | 关闭监视器再烧 |
| 幻觉 API | 编译报错/库不存在 | 编译日志 |
| 改安全限制 | 力矩限制被删，夹手 | 代码审查 |

> 教学价值：AI 写代码很快，但**它不知道物理世界的边界**。学生的价值是提供边界、验收和取舍。

## 11. 故障注入库

A 线物理故障每工位随机一个，教师提前记好；B 线用 C/E 两类做「降级」题。

| 故障 | 注入方法 | 期望排查路径 |
|---|---|---|
| A. 舵机 2 不响应 | 拔 2 号舵机线，或把 ID 改成 9 | `STATE` 的 `online` 少第 2 位 → 查线/查 ID |
| B. 灯环不亮/颜色卡住 | 拔掉灯环 DIN（只拔数据） | `led` 无反应 → 查 1.25mm 3P 口的 OUT/GND |
| C. 灯环一亮板子重启 | 备用板 + 限流电源，把亮度改到 100% 发全白 | 量 PH 口 5V 掉到多少 → 恢复 40% |
| D. 一动就复位 | 换 12V 2A 电源 | 量 12V 跌到多少 → 换 5A/加电容 |
| E. 灯头下垂 | 把力矩限制设到 10% | `STATE` raw 对但保持不住 → 调力矩/配重 |
