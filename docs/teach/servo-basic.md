# LT100 舵机基础：先读位置，再标定限位

- 日期：2026-11-21
- 例程：[examples/09_servo_basic/09_servo_basic.ino](../../examples/09_servo_basic/09_servo_basic.ino)
- 目标：让初学者看懂总线舵机的闭环、接线、位置读回和逐关节限位，再安全地发出第一条位置指令

## 1. 硬件路径

```text
12V 5A ── DC 5.5×2.1 ── 主控板 ── 3P 总线口 ── 3× ST3215（5264 串接）
USB-C ── CP2102 ── ESP32 UART0（烧录 / 串口）
ESP32 UART1：GPIO18=RX，GPIO19=TX，1Mbps ── 板载收发器 ── DATA
```

- 舵机是 **12V**，USB-C 只给 ESP32、OLED 和逻辑供电，**不给舵机**。
- **读取、标定、`POSE` 全程 12V 5A 必须接好并打开**；`TORQUE OFF` 只关输出力矩，不给舵机断电。12V 关着时舵机不响应，`STATE` 是 `online=0`，无法 `CAL MARK`。
- 主控板两个 3P 口内部并联，三只舵机串在同一条总线上，接哪个口都行。
- ST3215 本体的两个 5264-3P 口也**内部并联，没有输入/输出之分**：一个口接上一级，另一个口接下一只即可。
- 三只舵机 ID 设为 **1 / 2 / 3**，统一 **1Mbps**；ID 不能重复。新舵机用厂商 Web UI 或 URT-2 改 ID；公版固件只管理 ID 1..3，ID 不是这三个就不会出现在 `STATE` 里。
- LT100 是 **3R 平面臂**：肩/肘/腕三轴平行、在同一竖直平面内；标定和限位只涉及这个平面，没有偏航/滚转，也没有空间姿态。
- **断电插拔 3P 线**；带电热插拔可能烧总线或舵机。
- 12V 5A。12V 2A 在三只同时动作或堵转时会掉压复位。

## 2. 舵机是什么

普通直流电机通电就转，既不知道自己转了多少，也不会自己停在某个角度。舵机把下面几样装进壳体：

1. **直流电机**：转速高、扭矩小。
2. **减速齿轮**：降速、增扭；ST3215 堵转 30kg·cm，额定 10kg·cm。
3. **12 位磁编码器**：输出轴一圈分成 4096 格，约 0.088°/格。
4. **驱动与控制**：H 桥正反转，内部比较“目标位置”和“当前位置”，驱动电机减小误差。
5. **总线收发**：半双工 UART，一根 DATA 线；每个包带 ID。

闭环关系：

```text
目标位置 → 比较器 → H 桥 → 电机 → 减速齿轮 → 输出轴
              ↑                              │
              └──────── 编码器当前位置 ←─────┘
```

ESP32 不直接发 PWM，而是发一条“去某个位置”的总线命令；闭环在舵机内部完成。编码器是绝对式的，上电就知道轴的位置，不需要先找零点。

## 3. 0–4095 不是机械臂角度

编码器数的是 **舵机输出轴** 转了多少：

- 一圈 = 4096 格 = 360°。
- 一格 = 360 / 4096 ≈ **0.0879°**。
- `2048` 只是编码器中点（半圈），**不是机械臂的中位**。
- 本课按“一圈 4096 格”使用；如果关节真的会转过 360°，先查手册确认编码器是否多圈，不能直接把 4095 之后的 0 当连续角度。

舵盘装在哪一个齿、连杆朝哪个方向、关节在左还是右，都会让同一个 `2048` 对应完全不同的姿势。还会出现“数值变大，手臂反而向下”的方向差异。

因此：

- 不能把 `2048` 当默认安全中位；
- 不能抄别人的 MIN / MAX；
- 每台机器、每个关节都要在装配后单独标定。

## 4. 限位与安全

### 4.1 四道防线

1. **机械硬限位**：结构上限位块/拉杆，让手臂在物理上碰不到灯罩、底座和彼此。软件挂了还有它。
2. **每关节软件限位**：标定 MIN / MAX，存 NVS；目标越界直接拒绝。
3. **速度/加速度限制**：慢起慢停，避免灯头甩动；`POSE` 的 `speed` 限 1..52°/s（默认 22），`acc` 限 0..254。
4. **堵转/电流/温度保护**：本阶段尚未实现，后续补。

**软件限位不能替代机械硬限位。**

> **当前结构没有机械硬限位**：软件标定出来的限位是唯一保护；标定后要做低速端点验证，标定错/未标定就动会直接撞结构。加硬限位是学生改进项目，不是现状。

### 4.2 标定步骤

以腕关节 ID3 为例，手臂必须有人扶住：

```text
TORQUE 3 OFF
手移到可复现的参考姿态 → CAL REF 3 0
按方向选 CAL DIR 3 +1（或 -1）
慢慢把关节移到行程的一端 → CAL MARK 3 MIN
慢慢把关节移到另一端 → CAL MARK 3 MAX
CAL SAVE
LIMITS
```

> **前提：参考姿态必须在你允许的行程内。** 固件取两个端点之间**包含参考姿态**的那段弧作为行程；两端顺序随意。如果参考姿态在行程外（收纳位、停靠位、摆错），固件会选另一段补弧，标定仍会保存成功、显示有效，但实际行程是反的。这个错误不会报 `ERR 08`，只能由人保证。

- `CAL REF <id> <q>` 把当前姿态记为模型角 q（度）；参考姿态要能反复摆回来，q 由课程统一指定。`CAL DIR` 决定 raw 增大时 q 增大（`+1`）还是减小（`-1`）。
- **`MIN` / `MAX` 是行程两个端点的 raw 标签，不是 q 的最小/最大值，也不是机械上的“下 / 上”。** 固件把端点规范化成“沿 raw 增大方向从 MIN 走到 MAX”。**行程最好不要跨 0**：安装时先接标定工具扫一遍 raw；已经跨 0 的机器，标完后用 `CAL SPLIT` 保留含 Z 的一段，否则 `CAL SAVE` 回 `ERR 08`。q 方向反了只改 `CAL DIR`，不要靠交换 MIN/MAX 去修，那会改变行程弧。
- 标定全程 **12V 5A 必须接好并打开**；`TORQUE OFF` 只关输出力矩，不给舵机断电，舵机仍能回位置。12V 关着时 `STATE` 是 `online=0`，手能推动但读不到位置，无法 `CAL MARK`。
- `TORQUE OFF` 后关节会卸力，**手臂可能掉下来**；先扶住，先做腕，再做肘，最后做肩。
- 标定的是“安全端点”，不是机械硬限位的撞死点；端点之间还要留 `LIMIT_MARGIN=40` 格（约 3.5°）余量。
- 两端点跨度必须大于 `2 × 40 = 80` 格，否则 `MARK` 回 `ERR 08`。
- 标定值写进 NVS（命名空间 `lt100cal`，键 `cal`，带校验和），断电不丢。
- 换舵机、拆臂、换舵盘安装孔后，用 `CAL CLEAR <id>` 清掉重标；三个关节都清用 `CAL CLEAR all`。

### 4.3 行程跨 0：优先避开，已装好的可以截断

raw 是单圈值 0–4095，转过 4095 会回到 0。**安装时先接标定工具，手动扫一遍每个关节的行程，看 raw 是否经过 4095→0 这条缝；经过就换舵盘齿/安装位，把缝移出机械行程。** 这是最干净的做法，行程一点不丢。

原因不在限位算法，而在 ST3215 的默认角度模式（mode 0）：目标位置被当作 0–4095 的绝对角度，舵机按“目标 − 当前”的符号决定往哪边转，不会沿标定的弧走。举例：肩关节标出 `MIN=3396, MAX=650, Z=3851`（跨 0），当前 raw=3851；这时给一个正角度的目标 raw≈96，差值 `96 − 3851 = −3755`，舵机就往负方向一路走过去，直到撞出安全区被 `ERR 10` 拦下——这正是“拖到正角度、关节却往负的走”的原因。

**已经装好、来不及改机械时**，用 `CAL SPLIT <id> LOW|HIGH` 把跨 0 行程在接缝处截成两段，只保留一段：

- `LOW` 保留 `0..MAX`，`HIGH` 保留 `MIN..4095`；另一端是接缝，不是机械端点，手臂会在中途停住。
- **只有包含参考姿态 Z 的那一段能保存**；另一段不含 0°，固件拒绝。想用另一段，必须先回到步骤 3 重新定零点。
- 截断后 safe 区间仍按 `margin=40` 内缩。以肩为例：`CAL SPLIT 1 HIGH` 保留 `3396..4095`（约 61°），safe `3436..4055`；`0..650` 那段不可达。
- 流程：两个 `CAL MARK` 照常标（跨 0 不再在 MARK 阶段报错）→ `CAL SPLIT <id> HIGH|LOW` → `CAL SAVE`。网页在标完后会直接弹出两段让你确认。
- 截断是应急方案，不是等价替代：丢掉的行程拿不回来，接缝端也不是真实机械限位。以后有空还是建议对齿/重装，再完整重标。

行程不跨 0 时仍可以超过 180°，`rawToQ/qToRaw` 沿**标定弧**（MIN→MAX）换算，不是最短弧，没有歧义。已存在 NVS 的跨 0 标定可以读回检查，但 `valid=0`、不能用于 `JOG`/`POSE`，要先 `CAL SPLIT` 保留一段，或 `CAL CLEAR` 后重标。

> 多圈模式（mode 3，±7 圈绝对位置）能在硬件层面支持跨 0，但要改 EEPROM（解锁、角度限位归零、模式置 3、再锁），且掉电后圈数不保存。LT100 固件目前没有实现，也不在课程范围内。

## 5. 总线

### 5.1 接线

- 3P 丝印 `S / V / G`：S=DATA，V=舵机母线电压，G=GND。
- 两个 3P 口内部并联；5264 线把三只舵机串起来。
- ESP32 UART1：`GPIO18=RX`、`GPIO19=TX`，1Mbps。
- 板载收发器把 TX/RX 合成一根半双工 DATA，并负责方向切换。

### 5.2 数据包

```text
请求：FF FF | ID | LEN | INST | ADDR | DATA... | CHK
回包：FF FF | ID | LEN | ERR  | DATA...        | CHK
```

- 三只舵机都能收到请求，只有 ID 对上的那只执行并回包。
- `ID=0xFE` 是广播。
- `SMS_STS` 库负责组包、校验和收发；不要手拼字节。

### 5.3 电源预算

| 状态 | 电流 |
|---|---|
| 3 只待机 | 约 90mA |
| 3 只空载运动 | 约 0.54A |
| 单只堵转 | 2.7A |

- 5264 连接器约 3A，单只堵转已接近上限；不要让三只同时堵转。
- 灯环从板载 5V 取电，亮度上限 40%，不要为了“更亮”改上限。

## 6. 例程 09_servo_basic（公版）

### 6.1 上电行为

09 现在是一个很薄的整机 app：OLED、串口行输入和板级 HAL 之外，标定、限位、扭矩、失联和离线保护全部由公版 `LT100Core` 负责。上电只读状态，**不自动转动，也不自动上力**。

OLED 三行：

```text
UNCAL O1 C0 T0
J1 2048 J2 ----
J3 ---- 12.0V
```

第一行是模式、在线/标定/扭矩位；下面两行是 raw。模式含义：`UNCAL` 未标定、`CAL` 标定中、`READY` 就绪、`MOTION` 运动中、`FAULT` 故障、`ESTOP` 急停。

### 6.2 协议：LT100P/1

09 不再使用 `SCAN / READ / MARK / MOVE` 这套旧命令；它和公版其他应用说同一种 `LT100P/1` 文本协议。完整设计见 [common-platform.md §8](../design/common-platform.md)。

| 命令 | 作用 |
|---|---|
| `HELLO` | 协议/固件/功能位 |
| `STATE` | 模式、在线/标定/扭矩位、q/raw/load/cur/v/t、err、age |
| `STREAM ON\|OFF` | 10Hz 周期 `STATE`；默认关闭 |
| `TORQUE <id\|all> ON\|OFF` | 开/关输出力矩；OFF 用于手移标定；ON 要求该关节在标定行程内 |
| `CAL STATUS` | 每关节 ref/min/max/zero/dir/margin/valid |
| `CAL REF <id> <q>` | 当前姿态记为模型角 q（度，含参考姿态偏移） |
| `CAL DIR <id> +1\|-1` | raw 增大时 q 增大/减小 |
| `CAL MARK <id> MIN\|MAX` | 当前 raw 记为端点 |
| `CAL SPLIT <id> LOW\|HIGH` | 跨 0 时保留 `0..MAX` 或 `MIN..4095` 一段；必须含 Z |
| `CAL SAVE` / `CAL CLEAR <id\|all>` | 保存到 NVS / 清除标定 |
| `LIMITS` | 每关节 raw 端点与 safe 区间 |
| `POSE seq=<n> q=<q1,q2,q3> speed=<deg/s> acc=<0..254>` | 三关节目标；最新覆盖，不逐帧 ACK |
| `JOG seq=<n> id=<1..3> q=<deg> speed=<deg/s> acc=<0..254>` | 单关节测试；只要求该关节在线、标定有效、已上力 |
| `RAW id=<1..3> raw=<0..4095> speed=<deg/s> acc=<0..254>` | 安装定位：单颗、未标定、已上力；直接给 raw，无 safe 保护 |
| `STOP` / `ESTOP` / `CLEAR` | 原地停住 / 锁存急停并原地停住 / 清除故障 |

- `speed` 是度/秒，范围 1..52（默认 22）；固件内部按 `speed × 4096 / 360` 换成舵机刻度/秒。
- `acc` 是舵机加速度寄存器 0..254，不是物理 deg/s²。
- `CAL REF/DIR/MARK/SPLIT` 必须在 `TORQUE OFF` 下做；第一次这类命令会进入 `CAL` 模式，`POSE` 和 `TORQUE ON` 都会被拒绝，直到 `CAL SAVE` 或 `CAL CLEAR`。
- 三关节都有效才能 `POSE`；目标是度，但固件会先换算成 raw、检查 safe 区间，越界直接 `ERR 10`，不会静默钳位。
- `TORQUE ON` 前固件会核对：已标定的关节必须在线，且当前 raw 落在标定行程内。关节被手挪出行程时会拒绝（`ERR 10`），先把手臂推回行程再上力。上力时固件先把目标设为当前姿态，手臂不会突然跳向旧目标。
- `RAW` 是安装定位专用：总线上**只能有一颗**舵机、该关节**没有标定记录**、并且已经 `TORQUE <id> ON`。它直接写 0..4095 的 raw，**不经过 safe 区间**；用于装舵盘/对齿时把舵机转到合适角度。已有标定的关节只能用 `JOG`，不能走 `RAW`。
- `JOG` 是单关节版本：只动指定关节，其他关节不碰；单个舵机标定完就能做端点测试，不需要等三颗齐。一次性目标，不要求连续发送。
- **单圈与跨 0**：raw 只有 0–4095，转一圈回到 0。**安装时先接标定工具扫行程，尽量不跨 0**；已跨 0 时，两个 `MARK` 照常记录，`CAL SAVE` 会拒绝（`ERR 08`）直到用 `CAL SPLIT` 保留含 Z 的一段。截断后另一段不可达，接缝端不是机械端点。行程不跨 0 时仍可超过 180°，q 与 raw 的换算沿**标定弧**（MIN→MAX），不是最短弧，没有歧义。多圈模式未实现。

### 6.3 完整标定步骤

0. **配 ID（每颗单独做）**：新舵机出厂都是 ID1，三颗直接并上去会抢答。断电，只接一颗，上电；网页「配 ID」读当前 ID，按 **肩=1 / 肘=2 / 腕=3** 设好并贴标签；换下一颗重复。三颗都配好后再一起接。
1. **断电接线**：12V 先关，3P 总线串好，USB-C 接电脑，手扶住手臂。
2. **安装公版库**：Arduino IDE 需要 `LT100Core` 和 `LT100Board`（见 [platform/README.md](../../platform/README.md)）；用 CLI 则把 `--libraries` 指向 `platform\libraries`。
3. **打开 12V 5A**：舵机逻辑和电机都靠 12V，USB 只给 ESP32/串口。
4. **上传 09**；串口 115200，行尾 `Newline`。
5. **确认在线**：看 `STATE` 的 `online=7`（或网页 `3/3`）。只接一只时是 `1/3`，先查 12V、3P 线和 ID，不要继续。
6. **标定腕（建议先 ID3）**：扶住 → `TORQUE 3 OFF` → 手移到参考姿态 → `CAL REF 3 <q>` → `CAL DIR 3 +1|-1` → 移到行程一端 `CAL MARK 3 MIN` → 移到另一端 `CAL MARK 3 MAX`（顺序随意；**Z 必须在允许行程内**，否则固件会选补弧）。如果两端跨 0，网页会弹出两段让你选；命令行则补 `CAL SPLIT 3 HIGH|LOW`，只能选含 Z 的一段。
7. **保存**：`CAL SAVE` 写 NVS 并退出 `CAL`；只完成部分关节时模式仍是 `UNCAL`。
8. **重复肘、肩**：先腕、再肘、最后肩；负载越大越慢。
9. **上力 + 端点测试**：先把关节移回 safe 区间；单颗标完就可以先 `TORQUE <id> ON` 并用「端点测试」低速验证它（`JOG`），三颗都标完再 `TORQUE all ON` 做整机测试。

`CAL` 模式不是“暂停”：它是有意的标定会话。未保存的编辑掉电即丢；要放弃编辑又不改 NVS，直接重启。

### 6.4 网页标定/检测台

不想记命令时，用网页：

- 双击 `start-servo-console.bat`。它会先启动本机串口桥（用 .NET `SerialPort` 打开 CP210x，经 `ws://127.0.0.1:8771/serial` 转发），再打开页面。
- 页面优先连本机桥，不会弹 Web Serial 的端口选择；桥不可用时才回退 Web Serial。
- 桥在启动时打开串口，板子只复位一次；页面断开/重连时桥保持串口，不会反复复位，也不会出现 Web Serial 的 `BufferOverrunError`。
- 运行标定台时串口被桥占用；Arduino IDE 的串口监视器要先关掉，烧录前也要先关标定台。桥只监听 `127.0.0.1`，页面必须从 localhost 打开。
- 连接后页面自动发 `HELLO / STREAM ON / STATE / CAL STATUS / LIMITS`；左侧关节轨道显示 raw、q、电压、温度、负载、电流和 safe 区间。
- 右侧分「标定 / 状态 / 测试 / 配 ID」四个面板，共用同一次连接；标定向导只展开当前步骤，顶部「现在做」直接写出下一步动作，完成后自动进入下一步。顶部安全条是「停止 / 急停 / 解除急停」，并显示当前是否处于急停锁存。
- 「状态」只读：进入时自动刷新并显示时间戳，逐关节列出零点、方向、MIN/MAX 和 safe 区间；「读标定 / 读限位」会回显读取结果。
- 「测试」上半是单关节低速测试：输入任意目标 q（度）或拖滑块，10°/s 走过去，到位自动停；另有 ±5° 步进和 safe MIN/MAX 快捷键。只动当前关节，目标被限制在该关节 safe 区间内。
- 「测试」下半是整机低速测试（POSE）：三颗都有效、在线、上力且当前都在 safe 内后，点「开始整机测试（全行程）」；页面按 10 Hz 重发 `POSE`，依次把每个关节扫到 safe 两端（各内缩 10°），其余关节保持参考姿态，最后回参考姿态，到位/超时自动 `STOP`。**页面必须保持在前台**：固件 300 ms 收不到新 `POSE` 会判 `LinkLost`。
- 「配 ID」页下方是安装定位：只接一颗、关节未标定时，先「上力」，再输入 0..4095 的 raw 或点「去中点 2048」，把舵机转到装舵盘/对齿需要的角度；没有 safe 范围保护，速度从 5°/s 起。已有标定的关节会拒绝，请去「测试」页用 JOG。
- 串口日志收在页面底部的「展开」抽屉里，平时不占屏幕；需要看原始命令时再展开。
- 单关节测试只要求**该关节**在线、标定有效、已上力；整机 `POSE` 要求三关节齐全、都已上力，且当前都在 safe 内。
- `?mock=1` 是模拟模式，只验证界面和命令流，不连硬件。
- 桥不可用时回退 Web Serial，需要 Chrome / Edge 89+（或 Firefox 151+）；Safari 只能用桥。

> 08 串口控制台只负责灯、OLED 和板子状态，**不接舵机**；舵机标定/检测走 09 + 这个页面。

## 7. 反馈字段

| 字段 | 含义 |
|---|---|
| `raw` | 原始位置 0..4095 |
| `q` | 按标定换算的实测角（度）；未标定或离线时可能为 0 |
| `v` | 电压；`120` 表示 12.0V（0.1V 单位） |
| `t` | 温度 °C |
| `load` | `ReadLoad` 输出电压百分比 0..1000，带符号，**不是电流** |
| `cur` | `ReadCurrent` 原始电流寄存器值，不能直接当安培 |
| `online/cal/torque` | 每位一个关节的位掩码 0..7 |
| `err` | 最近错误码 |
| `age` | 距上次反馈读取的毫秒数 |

位置只说明“舵机轴在哪”，不说明“机械臂是否安全”；安全判断要用标定出来的 safe 区间。

## 9. 排错

| 现象 | 先检查 |
|---|---|
| `STATE` 只有 `online=1` | 12V 5A 是否打开；3P 线是否插好；ID 是否真是 1/2/3；USB 只给逻辑 |
| 只掉一只 | 那一只的 3P 线/ID；总线串联，前一只没接好会影响后面 |
| `ERR 06` | 该 ID 当前不在线；先看 `STATE`，查 12V 和线 |
| `ERR 08` | 两端太近（不足 80 格）、参考姿态离端点不足 40 格，或行程跨 0 还没选保留段；前两种把 Z 摆到行程中间、端点隔远再标，跨 0 用 `CAL SPLIT`。注意：Z 在允许行程外不会报 ERR 08，而是静默选补弧 |
| `ERR 09` | 未标定；先 `CAL REF/DIR/MARK`，再 `CAL SAVE` |
| `ERR 10` | 目标不在 safe 区间；用 `LIMITS` 看范围，不要硬闯 |
| `ERR 11` | 模式不允许：`CAL` 下不能 `POSE`/`TORQUE ON`；先 `CAL SAVE` 或 `CAL CLEAR` |
| `ERR 14` | NVS 存储失败；重新 `CAL SAVE`，仍失败查 NVS/分区 |
| `ERR 17` | 失联：300ms 没有新 `POSE`；应用持续发目标或主动 `STOP` |
| `TORQUE OFF` 后臂掉 | 卸力就会掉；先扶住，先做腕 |
| 方向反了 | 用 `CAL DIR` 设 ±1，不要靠交换 MIN/MAX 猜 |
| 12V 2A 掉压复位 | 换 12V 5A；不要让三只同时堵转 |
| 网页串口总断 / `BufferOverrunError` | 用 `start-servo-console.bat` 启动本机桥；关掉 Arduino 串口监视器；不要用旧页面 |
| 页面提示「本机串口桥不可用」 | 看 `.local/serial-bridge.log`；COM 是否被 IDE 占用、CP210x 是否存在；关掉占用后重开 .bat |
