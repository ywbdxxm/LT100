# LT100 舵机基础：先读位置，再标定限位

- 日期：2026-11-21
- 例程：[examples/09_servo_basic/09_servo_basic.ino](../../examples/09_servo_basic/09_servo_basic.ino)
- 目标：让初学者看懂总线舵机的闭环、接线、位置读回和逐关节限位，再安全地发出第一条位置指令

## 1. 硬件路径

```text
12V 5A ── DC 5.5×2.1 ── 主控板 ── 3P 总线口 ── 3× ST3215（5264 串接）
USB-C ── CP2102 ── ESP32 UART0（烧录 / 串口）
ESP32 UART1：GPIO18=RX，GPIO19=TX，1Mbps ── 板载收发器 ── DATA
```

- 舵机是 **12V**，USB-C 只给 ESP32、OLED 和逻辑供电，**不给舵机**。
- **读取、标定、MOVE 全程 12V 5A 必须接好并打开**；`TORQUE OFF` 只关输出力矩，不给舵机断电。12V 关着时舵机不响应，`SCAN` 会是 `0/3`，无法 `MARK`。
- 主控板两个 3P 口内部并联，三只舵机串在同一条总线上，接哪个口都行。
- 三只舵机 ID 设为 **1 / 2 / 3**，统一 **1Mbps**；ID 不能重复。新舵机用厂商 Web UI 或 URT-2 改 ID；09 例程只扫描 1..3（`SCAN_MAX`），ID 不是这三个就不会出现在扫描结果里。
- LT100 是 **3R 平面臂**：肩/肘/腕三轴平行、在同一竖直平面内；标定和限位只涉及这个平面，没有偏航/滚转，也没有空间姿态。
- **断电插拔 3P 线**；带电热插拔可能烧总线或舵机。
- 12V 5A。12V 2A 在三只同时动作或堵转时会掉压复位。

## 2. 舵机是什么

普通直流电机通电就转，既不知道自己转了多少，也不会自己停在某个角度。舵机把下面几样装进壳体：

1. **直流电机**：转速高、扭矩小。
2. **减速齿轮**：降速、增扭；ST3215 堵转 30kg·cm，额定 10kg·cm。
3. **12 位磁编码器**：输出轴一圈分成 4096 格，约 0.088°/格。
4. **驱动与控制**：H 桥正反转，内部比较“目标位置”和“当前位置”，驱动电机减小误差。
5. **总线收发**：半双工 UART，一根 DATA 线；每个包带 ID。

闭环关系：

```text
目标位置 → 比较器 → H 桥 → 电机 → 减速齿轮 → 输出轴
              ↑                              │
              └──────── 编码器当前位置 ←─────┘
```

ESP32 不直接发 PWM，而是发一条“去某个位置”的总线命令；闭环在舵机内部完成。编码器是绝对式的，上电就知道轴的位置，不需要先找零点。

## 3. 0–4095 不是机械臂角度

编码器数的是 **舵机输出轴** 转了多少：

- 一圈 = 4096 格 = 360°。
- 一格 = 360 / 4096 ≈ **0.0879°**。
- `2048` 只是编码器中点（半圈），**不是机械臂的中位**。
- 本课按“一圈 4096 格”使用；如果关节真的会转过 360°，先查手册确认编码器是否多圈，不能直接把 4095 之后的 0 当连续角度。

舵盘装在哪一个齿、连杆朝哪个方向、关节在左还是右，都会让同一个 `2048` 对应完全不同的姿势。还会出现“数值变大，手臂反而向下”的方向差异。

因此：

- 不能把 `2048` 当默认安全中位；
- 不能抄别人的 MIN / MAX；
- 每台机器、每个关节都要在装配后单独标定。

## 4. 限位与安全

### 4.1 四道防线

1. **机械硬限位**：结构上限位块/拉杆，让手臂在物理上碰不到灯罩、底座和彼此。软件挂了还有它。
2. **每关节软件限位**：标定 MIN / MAX，存 NVS；目标越界直接拒绝。
3. **速度/加速度限制**：慢起慢停，避免灯头甩动；例程把速度限制在 1..600。
4. **堵转/电流/温度保护**：本阶段尚未实现，后续补。

**软件限位不能替代机械硬限位。**

### 4.2 标定步骤

以腕关节 ID3 为例，手臂必须有人扶住：

```text
TORQUE 3 OFF
慢慢把关节移到安全下限 → MARK 3 MIN
慢慢把关节移到安全上限 → MARK 3 MAX
TORQUE 3 ON
LIMITS
```

- 标定全程 **12V 5A 必须接好并打开**；`TORQUE OFF` 只关输出力矩，不给舵机断电，舵机仍能回位置。12V 关着时 `SCAN` 会是 `0/3`，手能推动但读不到位置，无法 `MARK`。
- `TORQUE OFF` 后关节会卸力，**手臂可能掉下来**；先扶住，先做腕，再做肘，最后做肩。
- 标定的是“安全端点”，不是机械硬限位的撞死点；端点之间还要留 `LIMIT_MARGIN=40` 格（约 3.5°）余量。
- 两端点原始刻度差必须大于 `2 × 40 = 80` 格，否则 `MARK` 回 `ERR 08`。
- 标定值写进 NVS（命名空间 `lt100servo`，键 `min1/max1/set1` 等），断电不丢。
- 换舵机、拆臂、换舵盘安装孔后，用 `CLEAR <id>` 清掉重标。

### 4.3 行程跨过 0/4095

如果关节的行程跨过编码器的 0/4095 边界，简单数值 `min..max` 会失效。处理方式：

- 换一个舵盘齿，避开跨边界安装；或
- 扩展固件，用环形区间（取模）表示限位。

当前 09 例程不处理环形区间，遇到跨边界必须先改安装或改代码。

## 5. 总线

### 5.1 接线

- 3P 丝印 `S / V / G`：S=DATA，V=舵机母线电压，G=GND。
- 两个 3P 口内部并联；5264 线把三只舵机串起来。
- ESP32 UART1：`GPIO18=RX`、`GPIO19=TX`，1Mbps。
- 板载收发器把 TX/RX 合成一根半双工 DATA，并负责方向切换。

### 5.2 数据包

```text
请求：FF FF | ID | LEN | INST | ADDR | DATA... | CHK
回包：FF FF | ID | LEN | ERR  | DATA...        | CHK
```

- 三只舵机都能收到请求，只有 ID 对上的那只执行并回包。
- `ID=0xFE` 是广播。
- `SMS_STS` 库负责组包、校验和收发；不要手拼字节。

### 5.3 电源预算

| 状态 | 电流 |
|---|---|
| 3 只待机 | 约 90mA |
| 3 只空载运动 | 约 0.54A |
| 单只堵转 | 2.7A |

- 5264 连接器约 3A，单只堵转已接近上限；不要让三只同时堵转。
- 灯环从板载 5V 取电，亮度上限 40%，不要为了“更亮”改上限。

## 6. 例程 09_servo_basic

### 6.1 上电行为

- 扫描 ID 1..3，读位置、电压、温度、负载。
- 从 NVS 读取限位。
- **不自动转动**；`MOVE` 只有在标定过、且目标在安全区内才执行。
- OLED 三行：

```text
SERVO 3/3 CAL
1:2048 2:2051
3:2000 V:12.0
```

第一行是在线数量 + 是否有关节已标定（`CAL` / `RAW`）。

### 6.2 命令表

| 命令 | 作用 |
|---|---|
| `SCAN` | 扫描 ID 1..3，只读 |
| `READ <id>` | 读位置、电压、温度、负载 |
| `LIMITS` | 查看已存限位 |
| `MARK <id> MIN\|MAX` | 把当前位置记为端点，写 NVS |
| `TORQUE <id> ON\|OFF` | 开/关输出力矩；OFF 用于手移标定 |
| `CLEAR <id>` | 清除该关节限位 |
| `MOVE <id> <pos> [speed]` | 只在 safe 区间内动；速度 1..600 |

错误码：

| 码 | 含义 |
|---|---|
| `01` | 未知命令 |
| `02` | 参数缺失或格式不对 |
| `03` | 数值越界 |
| `05` | 单行超过 80 字节 |
| `06` | 舵机离线 |
| `07` | 写指令没有 ACK |
| `08` | MIN/MAX 太近，或端点顺序不成立 |
| `09` | 未标定，`MOVE` 被拒绝 |
| `10` | 目标超出 safe 区间 |

### 6.3 完整操作

1. **断电接线**：12V 先关，3P 总线串好，USB-C 接电脑，手扶住手臂。
2. **打开 12V 5A**：舵机逻辑和电机都靠 12V，USB 只给 ESP32/串口。等 ESP32 启动。
3. 上传 09；串口 115200，行尾 `Newline`。
4. `SCAN`：应看到 `3/3 online`。若 `0/3`，先查 12V 是否打开、3P 线和 ID，不要继续。
5. `LIMITS`：新机器三个 `UNSET`；此时 `MOVE` 回 `ERR 09`。
6. 标定 ID3：`TORQUE 3 OFF` → 手移到下限 → `MARK 3 MIN` → 手移到上限 → `MARK 3 MAX` → `TORQUE 3 ON`。**整个标定过程 12V 保持打开；TORQUE OFF 只关输出力矩，不给舵机断电。**
7. `LIMITS` 确认 safe 区间；`MOVE 3 安全位置 250`；`READ 3` 验证实际位置。
8. 重复 ID2、ID1；负载越大越慢，先腕、再肘、最后肩。

`MOVE` 不会自动回到原位；要回去就再发一条目标在 safe 区间内的 `MOVE`。

### 6.4 网页标定台

不想记命令时，用网页：

- 双击 `start-servo-console.bat`，或从主页舵机章节打开 `web/servo.html`。
- 连接 CP210x 串口后，页面自动发 `SCAN` + `LIMITS`；关节卡片显示在线、位置、电压、温度和 safe 区间。
- 按「卸力 → MARK MIN → MARK MAX → TORQUE ON」点按钮；每次操作后页面自动刷新。
- 在 safe 区间内填目标，发 `MOVE`；不会自动回位。
- `?mock=1` 是模拟模式，只验证界面和命令流，不连硬件；真实 Web Serial 的端口选择必须由人点。
- 需要 Chrome / Edge 89+（或 Firefox 151+）；Safari 不支持，页面必须从 localhost/HTTPS 打开。

## 7. 反馈字段

| 字段 | 含义 |
|---|---|
| `pos` | 原始位置 0..4095 |
| `v` | 电压；串口打印为 `12.0V`，底层 `ReadVoltage` 原始值 120（0.1V 单位） |
| `t` | 温度 °C |
| `load` | 负载 0..1000，带符号 |

位置只说明“舵机轴在哪”，不说明“机械臂是否安全”；安全判断要用标定出来的 safe 区间。

## 8. 构建与实测

- 编译：`341989 B / 26% flash`，`25664 B / 7% RAM`，`esp32:esp32:esp32`。
- 上传：串口写入后 `Hash of data verified`。
- 命令路径实测：
  - `SCAN` 回 `0/3 online`（本次舵机没有响应；先查 12V/3P 线）；
  - `LIMITS` 三个 `UNSET`；
  - `MOVE` 回 `ERR 09`；
  - 用临时 NVS 种子写入 ID1 `1000..2000` 后，`MOVE 1 2048` 被 `ERR 10` 拒绝，`MOVE 1 1500` 通过限位检查后因舵机离线回 `ERR 06`；
  - 测试后用 `CLEAR 1` 清除，未留下测试限位。
- 原始串口日志在 `.local/servo-basic-*.log` 与 `.local/servo-limits-*.log`。
- 网页标定台用 `web/servo.html?mock=1` 实测完整流程：连接 3/3 → 卸力 → 模拟位置 1300 → MARK MIN → 模拟位置 2300 → MARK MAX → safe `1340..2260` → TORQUE ON → `MOVE 2000`，卡片位置更新为 2000。**这是 mock 界面/命令流测试，不是实机运动；真实 Web Serial 的端口选择需要人工点击，未自动化。**

> 当前**没有验证实机转动和实机标定**：`SCAN` 是 `0/3`，舵机没有响应。接上 12V、确认 `3/3 online` 后，再按 §6.3 做第一次标定和 `MOVE`；不要把“编译通过/命令路径通过”当成“机械动作已验证”。

> `0/3` 不是“命令没发出去”，而是总线读回如实报告离线。先查 12V、3P 线和 ID，不要先怀疑库。

## 9. 排错

| 现象 | 先检查 |
|---|---|
| `SCAN` 回 0/3 | 12V 5A 是否打开；3P 线是否插好；ID 是否真是 1/2/3；USB 只给逻辑 |
| 只掉一只 | 那一只的 3P 线/ID；总线串联，前一只没接好会影响后面 |
| `ERR 06` | 该 ID 当前不在线；先 `SCAN` |
| `ERR 07` | 写指令没有 ACK；查 ID、总线、电源 |
| `ERR 08` | MIN/MAX 太近（少于 80 格）；重新标定 |
| `ERR 09` | 未标定；先 `MARK id MIN/MAX` |
| `ERR 10` | 目标不在 safe 区间；用 `LIMITS` 看范围 |
| `TORQUE OFF` 后臂掉 | 卸力就会掉；先扶住，先做腕 |
| 方向反了 | 安装方向不同是正常的；限位仍用原始 MIN/MAX |
| 12V 2A 掉压复位 | 换 12V 5A；不要让三只同时堵转 |

## 10. 下一步
