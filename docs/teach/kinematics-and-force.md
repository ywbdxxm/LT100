# LT100 运动学与力学教学手册

- 版本：**v0.1（2026-11-21 初稿）**
- 适用：LT100 三轴机械臂台灯（微雪 Servo Driver with ESP32 + 3×ST3215-C018）
- 定位：**教师用教学手册**，配套 [design.md](../design/design.md)（设计）与 [course-4h.md](course-4h.md)（4h 课）
- 一句话：本手册只干两件事——**把「机械臂在哪」算清楚（运动学）**、**把「机械臂使多大劲」量清楚（力学）**

## 0. 先划定边界

| 是 | 不是 |
|---|---|
| **3R 平面臂**：肩、肘、腕三轴平行，都在同一竖直平面内 | 不是 6 轴空间机械臂，没有偏航/滚转 |
| 绝对角度控制，上电不用回零 | 没有外部编码器，精度受背隙限制 |
| 电流可回读，能粗略估计力矩 | 没有力矩/力传感器，读的是电流 |
| 腕只控**灯头俯仰** | 没有夹爪，不讲抓取规划 |
| 单臂、无视觉 | 不讲视觉伺服、VLA |

> **对学生要说清楚**：这是一台"能被完整算明白"的机械臂，不是缩小版工业机器人。算得明白，才测得出误差。

## 1. 坐标系与实测参数

### 1.1 定义

```text
        y
        ↑
        │        ● 灯罩中心 (x_e, y_e)
        │       /
        │      / l3
        │     ● 腕 (x_w, y_w)
        │    /
        │   / l2
        │  ● 肘
        │ /
        │/ l1
  ──────●──────────────→ x
        肩 (0, 0)
```

| 符号 | 含义 | 初值 | 备注 |
|---|---|---|---|
| `l1` | 肩轴 → 肘轴 | ≈180 mm | **待实测**，卷尺量轴心距 |
| `l2` | 肘轴 → 腕轴 | ≈180 mm | 同上 |
| `l3` | 腕轴 → 灯罩中心 | ≈80–100 mm | 待实测，量到几何中心 |
| `θ1` | 上臂绝对角（相对 +x 轴） | 由舵机 1 换算 | 逆时针为正 |
| `θ2` | 肘关节**相对**角 | 由舵机 2 换算 | 伸直为 0° |
| `θ3` | 腕关节**相对**角 | 由舵机 3 换算 | 决定灯头朝向 |
| `ψ` | 灯头朝向（绝对角） | `ψ = θ1 + θ2 + θ3` | 竖直向下 = −90° |

### 1.2 零位标定（上课第一件事）

舵机读数是"舵机自己的角度"，≠ 我们的绝对角。必须标定一次：

1. 把臂摆到**已知几何姿态**（推荐：上臂竖直向上、肘伸直、灯头朝正前方）。
2. `pos` 读三个舵机的原始角度，记为 `raw1/raw2/raw3`。
3. 建立换算：

```text
θ1 = raw1 − raw1_zero
θ2 = raw2 − raw2_zero      # 注意方向：若实物反向，取负号
θ3 = raw3 − raw3_zero
```

4. 写进固件常量表，**不许每节课临时改**。

> 零位不准，后面所有误差分析都白做。这一条要写进课前检查清单。

### 1.3 测量记录表（每人一张）

| # | 项 | 方法 | 记录 |
|---|---|---|---|
| 1 | `l1` | 卷尺，两轴中心 | ____ mm |
| 2 | `l2` | 同上 | ____ mm |
| 3 | `l3` | 腕轴 → 灯罩几何中心 | ____ mm |
| 4 | 整机高度 | 灯头抬起最高点 | ____ mm（约 380） |
| 5 | 上臂质量 | 电子秤 | ____ g |

| 8 | `raw1_zero` / `raw2_zero` / `raw3_zero` | `pos` | ____ / ____ / ____ |

## 2. 正运动学（FK）：给角度，算位置

```text
x_w = l1·cosθ1 + l2·cos(θ1 + θ2)
y_w = l1·sinθ1 + l2·sin(θ1 + θ2)

x_e = x_w + l3·cos(θ1 + θ2 + θ3)
y_e = y_w + l3·sin(θ1 + θ2 + θ3)
```

### 2.1 课堂流程（45 分钟）

1. **讲 10 分钟**：为什么三角函数就能描述机械臂（把每根杆看成一个向量，向量首尾相接）。
2. **算 15 分钟**：发 12 组角度表，学生用计算器/Excel 算 `(x_w, y_w)` 与 `(x_e, y_e)`。
3. **量 15 分钟**：`move` 到同一组角度，卷尺量灯罩中心实际位置。
4. **对 5 分钟**：算误差 `Δ = √(Δx² + Δy²)`，填表、算平均。

### 2.2 算例

设 `l1 = l2 = 180 mm`，`l3 = 90 mm`，`θ1 = 60°, θ2 = 30°, θ3 = 0°`：

```text
x_w = 180·cos60° + 180·cos90° = 90 + 0 = 90 mm
y_w = 180·sin60° + 180·sin90° = 155.9 + 180 = 335.9 mm
x_e = 90 + 90·cos90° = 90 mm
y_e = 335.9 + 90·sin90° = 425.9 mm
```

> 手算一遍，学生才会相信公式不是玄学。

### 2.3 误差从哪来（重点讲，别跳过）

| 来源 | 典型量级 | 怎么减小 |
|---|---|---|
| 连杆长度估计偏差 | ±5 mm | 实测，不用照片估 |
| 零位偏移 | ±3° → 末端 ±10 mm | 认真标定 |
| 关节背隙 | 0.5–2° | 正反向各测一次取平均 |
| 轴心与舵盘不同心 | 1–2 mm | 装配时对中 |
| 温度形变 | 可忽略 | — |

**结论**：预期末端误差 **10–25 mm**，属于正常。不要追求"零误差"，要讲清"误差有哪些、哪个最大"。

## 3. 工作空间：它能到哪

### 3.1 方法：撒网格，画散点

```text
θ1 ∈ [−60°, 120°]，步长 5°
θ2 ∈ [−10°, 150°]，步长 5°
θ3 = −(θ1+θ2) − 90°        # 固定灯头竖直向下
→ 每个组合算一个 (x_e, y_e) → 散点图
```

### 3.2 该看出来的四件事

| 现象 | 解释 |
|---|---|
| **外边界** ≈ `l1 + l2 + l3` = 450 mm | 完全伸直 |
| **内边界** ≈ abs(l1 − l2) | 折回肩轴（实物会被灯罩/底座挡住） |
| **奇异点** `θ2 = 0°`（全伸）、`θ2 = 180°`（全折） | 雅可比退化，逆解不唯一，速度传递比极端 |
| **软限位比理论边界小一圈** | 固件钳位为防撞灯罩/底座（见 [course-4h.md §3](course-4h.md) 硬件契约） |

> 演示：伸到最直，让学生推灯头——"推得动吗？"这就是奇异点：力臂最大、速度传递比无穷大。

### 3.3 与软限位的关系

| 关节 | 软限位 | 依据 |
|---|---|---|
| 肩（ID 1） | −20° ~ 80° | 防止撞底座/桌面 |
| 肘（ID 2） | 0° ~ 110° | 防止自碰撞灯罩 |
| 腕（ID 3） | −30° ~ 60° | 防止灯头翻过头 |

**红线**：软限位不许删、不许放宽（[course-4h.md §3](course-4h.md)）。

## 4. 逆运动学（IK）：给位置，算角度

### 4.1 余弦定理求解

```text
r² = x² + y²                                   # 目标腕点
cosθ2 = (r² − l1² − l2²) / (2·l1·l2)           # 必须 −1 ≤ cosθ2 ≤ 1
θ2 = ±acos(cosθ2)                               # 两解：肘上 / 肘下
θ1 = atan2(y, x) − atan2(l2·sinθ2, l1 + l2·cosθ2)
θ3 = ψ_目标 − (θ1 + θ2)                         # ψ 例：−90° 灯头垂直向下
```

### 4.2 三个必须讲的点

1. **双解**：同一个点有两组角度（肘上/肘下）。选哪组？
   - 看是否撞灯罩/底座（软限位过滤）；
   - 看灯头朝向是否物理可达到；
   - 看力矩需求（选电流小的那组，见 §7）。
2. **越界**：`r > l1 + l2` 时 `cosθ2 > 1`，无解。固件必须**拒绝并报错**，不能硬算出一个角度。
3. **冗余**：3 个自由度 = 2 个位置约束 + 1 个姿态约束，刚好解出；姿态一变，位置就受限——这就是"为什么灯头不能随便转"。

### 4.3 验证实验（30 分钟）

| 目标 (x, y) | 预测 θ1/θ2/θ3 | `move` 后实测位置 | 误差 |
|---|---|---|---|
| (150, 250) | | | |
| (200, 300) | | | |
| (250, 310) | | | |
| (400, 100) 越界 | 应报错 | 未动作 | — |

> 越界那一行是重点：**看固件会不会拒绝**。会拒绝，才说明软限位是真的。

## 5. 静力学：力矩 = 重量 × 水平力臂

### 5.1 核心公式

```text
τ_关节 = g · Σ (m_i · d_i)
    m_i = 该关节之后所有零件的质量（kg）
    d_i = 这些零件重心到关节轴的**水平距离**（m），不是直线距离
    g   = 9.81 m/s²
单位换算：1 kg·cm = 0.0981 N·m
```

### 5.2 三个关节的估算（引用 [design.md §3.2](../design/design.md)）

| 关节 | 要举的部分 | 静态扭矩（水平伸直） | 额定 10 kg·cm 够吗 |
|---|---|---|---|
| 肩 | 全部臂 + 灯头 ≈0.5–0.6 kg | **10–14 kg·cm** | ❌ 长期会超 |
| 肘 | 灯头 + 上臂 ≈0.3 kg | 4–5 kg·cm | ✅ |
| 腕 | 灯头 ≈0.2 kg | 1–2 kg·cm | ✅ 余量很大 |

**算例（肩，水平伸直）**：

```text
m = 0.55 kg，重心水平距离 d = 0.20 m
τ = 9.81 × 0.55 × 0.20 = 1.08 N·m = 11.0 kg·cm
```

### 5.3 为什么肩要用 30 kg·cm

- 摩擦、加速度、灯头偏载会让实际需求更高；
- 额定 10 kg·cm **长期保持水平会超**，所以选 30 kg·cm 级（堵转 30，额定 10）；
- 真正的工程解不是继续加大舵机，而是**加弹簧配重**把静态负载卸掉。

> 这一节讲完，学生就该明白"选型不是越大越好，是算出来的"。

## 6. 动态：为什么不能突然甩

| 量 | 说明 |
|---|---|
| 惯性力矩 | `τ = I·α`，加速度越大、力臂越长，瞬间需求越高 |
| 灯头摆动 | 末端是悬空的灯罩，急停会晃 → 必须 S 曲线 |
| 掉压 | 3 只同时堵转最坏 8.1 A，12V 2A 电源会复位 |

**教学点**：静态算的是"站着不动要多大劲"，动态算的是"动起来要多大劲"，后者还要叠加惯性；所以固件必须有**速度/加速度限制**（[design.md §5.2](../design/design.md) 第 4 条）。

## 7. 用电流当"测力计"

### 7.1 标定关系

ST3215-C018 公开数据：

| 量 | 值 |
|---|---|
| 堵转电流 | 2.7 A @ 30 kg·cm |
| 空载电流 | 180 mA |
| 静态电流 | ≈30 mA |

粗略线性化：

```text
每 1 kg·cm ≈ (2.7 − 0.18) / 30 ≈ 0.084 A
或：1 A ≈ 11.9 kg·cm
```

### 7.2 用法与限制

| 能用 | 不能用 |
|---|---|
| 判断"有没有负载"、"大概多重" | 当精密力矩传感器 |
| 做接触检测（阈值） | 测 0.5 kg·cm 级别的小力 |
| 比较配重前后差异 | 跨温度精确换算 |

**误差来源**：摩擦（尤其减速箱）、电流-力矩非线性、温升降额、母线电压波动。**这个误差本身就是教学内容**。

### 7.3 姿态-电流实验（30 分钟）

1. 肩从**水平**（θ1 = 0°）每抬 10° 停 3 秒，记录 `pos` 的电流；
2. 画「角度 vs 电流」曲线；
3. 预期：水平电流最大、竖直最小（力臂 `d = r·cosθ1` 变短）；
4. 用 `τ = m·g·d` 反算对比，讨论误差。

### 7.4 配重对比实验（20 分钟）

| 条件 | 同一姿态（肩水平）电流 | 结论 |
|---|---|---|
| 无配重 | ____ mA | 基准 |
| 挂弹簧/配重块 | ____ mA | 电流下降 = 力矩被卸掉 |

> 这一格数据，比十页 PPT 更能说明"为什么要配重"。

## 8. 力控与柔顺：从"量力"到"让"

```text
循环：
  读电流
  if 电流 > 阈值:  → 判定接触
       降力矩 -> 反向退让 -> 灯变红 -> 记事件
  else: 正常保持
```

| 概念 | 在本机上的实现 |
|---|---|
| 力矩限制 | 设置舵机最大输出力矩（低于堵转） |
| 柔顺/阻抗 | 被推时允许让位，松手回位 |
| 失效保护 | 舵机离线 → 其余关节继续，打印 `ERR servo <id> offline` |

> 演示：手顶灯头 → 变软、亮红、后退；松手 → 恢复预设。**这一下就把"具身"讲明白了**。

## 12. 安全红线（与 [design.md §5.3](../design/design.md) 一致）

1. 30 kg·cm 关节夹手很疼 → 固件必须限力矩，机械留缝。
2. 上电不自动动；`move`/`go` 必须检查软限位。
3. 舵机线不许带电热插拔。
4. 12V 入口加保险丝；电源 ≥12V 5A。
5. 灯环亮度 ≤40%（102/255），**不许全白**（超板载 5V 预算）。

## 13. 常见错误（教师重点讲）

| 错误 | 现象 | 怎么发现 |
|---|---|---|
| 用舵机原始角当绝对角 | 算出来位置全错 | 没做零位标定 |
| 力臂用直线距离 | 力矩算大 1.5–2 倍 | 检查 `d = r·cosθ` |
| 忽略灯罩碰撞 | IK 解合法但实物撞罩 | 软限位 + 手扶测试 |
| 把电流当精密力矩 | 误差 20%+ 还当真 | 标定表 + 误差讨论 |
| 直接 `move` 到极限角 | 堵转、发热、掉压 | 先 `limits` 再 `move` |
| 认为"舵机内部闭环 = 系统精度" | 重复精度差 3–5° | K4 背隙实验 |

## 附录 B：Python 参考片段（可直接抄进 `tools/kinematics.py`）

```python
import math

def fk(t1, t2, t3, l1, l2, l3):
    xw = l1*math.cos(t1) + l2*math.cos(t1+t2)
    yw = l1*math.sin(t1) + l2*math.sin(t1+t2)
    xe = xw + l3*math.cos(t1+t2+t3)
    ye = yw + l3*math.sin(t1+t2+t3)
    return (xw, yw, xe, ye)

def ik(x, y, psi, l1, l2, l3):
    r2 = x*x + y*y
    c2 = (r2 - l1*l1 - l2*l2) / (2*l1*l2)
    if not (-1.0 <= c2 <= 1.0):
        raise ValueError("目标超出工作空间")
    t2 = math.acos(c2)                      # 肘上一解；取负号得肘下
    t1 = math.atan2(y, x) - math.atan2(l2*math.sin(t2), l1 + l2*math.cos(t2))
    t3 = psi - (t1 + t2)
    return (t1, t2, t3)
```

> 单位统一用**米**或**毫米**，别混。角度用弧度，`move` 前再转成度。
