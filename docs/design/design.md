## 1. 定位与边界

### 是

- 一个能讲清楚「机械结构 → 舵机 → 总线 → 控制 → 灯光」的完整实物
- 每个环节都能测：扭矩、电流、角度、温度、灯环电流/颜色
- 允许拆、允许改、允许失败；坏了能修，改了能对比
- 结构尽量模块化，单个关节/灯头可以独立更换

### 不是

- 不追求量产成本、认证、外观工艺
- 不追求静音、长寿命、工业级可靠性
- 不为了「像产品」而隐藏走线或牺牲可观察性
- 不把「能亮」当成验收；每个功能要有可测量的证据

> 产品思维问「能不能卖」，教具思维问「学生能不能看见、摸到、测到、改到」。

### 1.1 当前版本教什么

| 层 | 能讲什么 | 学生能测到什么 |
|---|---|---|
| **结构** | 三轴悬臂、关节、配重、双支撑 | 重量、重心、关节扭矩 |
| **执行** | 舵机选型、减速比、堵转/额定、保持电流 | 角度-电流曲线、温升 |
| **控制** | 闭环、软限位、力矩限制、轨迹规划 | 阶跃响应、重复精度、背隙 |
| **通信** | 半双工总线、ID、波特率、协议包 | 总线扫描、抓包 |
| **电源** | 12V 舵机母线、板载 5V 灯环、峰值电流、共地 | 功耗表、掉压现象 |
| **灯光** | WS2812 单线协议、像素映射、颜色/亮度、电流 | 逐颗点亮、颜色顺序、电流 |
| **软件** | AI agent 写规格 → 生成 → 烧录 → 验证 | 串口日志、测试 PASS/FAIL |
| **系统** | 集成、安全、失效保护、30 分钟连续跑 | 整机测试报告 |

> 传感（BH1750/人体感应）和光学（COB/照度/显指）是**后续升级**内容，
> 当前小 board 没有引出 GPIO，做不了。升级路线见 §10。

### 1.2 学习目标（当前版本）

做完这套教具，学生应该能：

1. 画出「结构 → 执行 → 控制 → 通信 → 电源 → 灯光」的系统框图，并指出每一层的输入/输出。
2. 称重、量臂长、算关节扭矩，解释为什么肩部用 30kg 舵机而腕部不用。
3. 通过串行总线读舵机的位置/电流/温度，写一个能设 ID、设限位、读状态的脚本。
4. 用 WS2812 灯环做颜色/亮度/状态效果，理解像素映射、颜色顺序和板载 5V 限流。
5. 让 AI agent 按硬件契约改代码、编译、烧录，并用硬件证据验收。

**后续升级目标**（需要换板）：环境光自适应、人体感应、COB 阅读灯、照度/显指测量。

## 3. 系统架构

```text
              ┌─────────────────────────────┐
              │           灯头              │
              │ 10cm 罩 + 24 灯 WS2812 环   │
              │ + 乳白扩散片 + 白色反光膜(选)│
              └──────────────┬──────────────┘
                             │ 腕关节（ST3215）
              ┌──────────────┴──────────────┐
              │          上臂（18cm）        │
              └──────────────┬──────────────┘
                             │ 肘关节（ST3215）
              ┌──────────────┴──────────────┐
              │          下臂（18cm）        │
              └──────────────┬──────────────┘
                             │ 肩关节（ST3215）
              ┌──────────────┴──────────────┐
              │      底座（配重/走线）       │
              │  主控板 + 12V/5V 电源入口    │
              └──────────────┬──────────────┘
                             │
                    12V 5A
```

### 3.1 电气拓扑

```text
12V 5A ── 主控板 DC5.5×2.1 ── 3P 总线口 ── 3× ST3215（5264 串接）
                              └── 板载 5V ── ESP32/OLED/板载 RGB/24 灯环

主控板 1.25mm 3P（板子标 PH1.25）：
  5V  → 灯环 5V（24 灯，固件限 40%）
  GND → 灯环 GND
  OUT → 灯环 DIN（GPIO23）

USB-C ── 电脑（烧录/串口 115200）
```

**为什么不需要第二个电源**：舵机是 12V，灯环是 5V；24 灯环在 40% 上限约 0.58A，
加 ESP32/OLED 约 0.78A，板载 5V 约 1A 够用。全白 1.44A 会超过，所以 40% 是硬上限。

**「智能」从哪来**：不是 WiFi 本身，而是「指令 → 动作 → 灯光反馈」的闭环。当前版本的三条：

1. **姿态记忆**：舵机编码器读角度，存预设，一键回到阅读/写作/收纳姿态。
2. **灯光状态**：空闲暖白、运动蓝、错误红；动作和颜色同步。
3. **AI 写代码**：学生写规格，AI 改固件，硬件验证；这是 4h 课的主线。

> 环境光自适应、人体感应、COB 阅读灯是后续升级，见 §10。

### 3.2 关节与负载

按照片估算（零件未称重）：

| 关节 | 要举的部分 | 静态扭矩（水平） | 动态余量后 | 额定 10kg·cm 是否够 |
|---|---|---|---|---|
| 肩 | 全部臂 + 灯头，约 0.5–0.6kg | 10–14 kg·cm | 15–21 kg·cm | **不够，长期会超** |
| 肘 | 灯头 + 上臂，约 0.3kg | 4–5 kg·cm | 6–8 kg·cm | 够 |
| 腕 | 灯头，约 0.2kg | 1–2 kg·cm | 2–3 kg·cm | 够，余量大 |

**结论**：肩部用 30kg 级是合理的；肘、腕明显过裕。真正该做的是**加弹簧配重**，而不是继续加大舵机。

### 3.3 电源预算

| 状态 | 电流 |
|---|---|
| 3 只舵机待机 | 约 90mA |
| 3 只舵机空载运动 | 约 0.54A |
| 单只舵机堵转 | 2.7A |
| 3 只同时堵转（最坏） | 8.1A |
| 24 灯环 30% 亮度 | 约 0.43A |
| 24 灯环 40% 亮度 | 约 0.58A |
| 24 灯环全白（禁止） | 约 1.44A |
| 板载 5V 总电流（40%） | 约 0.78A |

- **舵机电源至少 12V 5A**；12V 2A 会在同时动作时掉压复位。
- **灯环从主控板板载 5V 取电**；24 灯 40% 上限，按板载 5V 约 1A 估算，留约 0.2A 余量。
- 12V 总线入口加 1000µF 电解 + 0.1µF 陶瓷（可选；需要焊接）。
- 5264 连接器额定约 3A；单只舵机堵转 2.7A 已接近上限，固件力矩限制建议 ≤70%。

## 4. 机械设计要点

### 4.1 关节

- 每个关节目前看起来是**单边支撑**：舵盘在一侧，另一侧没有轴承。
- 后果：输出轴同时承受扭矩和侧向弯矩，容易晃、扫齿、编码器漂移。
- 改进：另一侧加一个 5mm 内孔轴承，做双支撑；舵盘螺丝涂螺纹胶。
- 底座建议加推力轴承，承受悬臂带来的倾覆力矩。

### 4.2 配重

- 目标：让肩关节在常用姿态下接近重力平衡。
- 方案 A：拉簧，从底座连到下臂中部（最像 Anglepoise）。
- 方案 B：下臂尾部加配重块。
- 方案 C：扭簧藏在关节里（最好看，最难做）。
- 验收：在常用姿态下，舵机保持电流从「明显发热」降到「微温」。

### 4.3 走线

- 现在的线在关节外侧，反复弯折会断。
- 走臂内侧的槽，关节处留**服务环**（多留 2–3cm）。
- 用硅胶线（多股细丝），不要在关节处用硬线。
- 灯环线（5V/GND/DIN）与舵机线分开走，避免灯环 PWM 电流干扰总线。

### 4.4 底座

- 底座要够重：灯头伸到最远时不能翻。
- 估算：整机重心最远约在底座边缘外 10cm，底座配重至少 1kg。
- 底部加硅胶脚垫。

### 4.5 灯头

- 灯环：24 灯、72mm 外径、54mm 内径、白板、5V。
- 固定：双面胶或 3 个 M2.5 尼龙柱；灯环很轻，不需要铝板/散热片。
- 扩散片：Ø100×2mm 乳白亚克力，离灯环 10–15mm。
- 反射：灯罩内壁橙色，贴白色 PET 反光膜（选装）让颜色更干净。
- 走线：灯环 3 根线沿臂内侧走到主控板 1.25mm 3P 口；留服务环。

## 5. 控制与固件

### 5.1 总线

- 3 只舵机 ID 设为 1/2/3，统一 1Mbps。
- 主控板板内 UART1：GPIO18=RX，GPIO19=TX。
- 建议先用板载 Web UI 或 URT-2 在 PC 上验证 ID 和方向。
- 上电先读位置、电压、温度；任何一只不在预期范围就进入安全姿态。

### 5.2 固件功能（最小集）

1. **绝对角度控制**：磁编码器，上电不需要回零。
2. **软限位**：每个关节设 min/max，防止撞灯罩/底座。
3. **力矩限制**：堵转/碰撞时降力矩，而不是硬顶。
4. **速度/加速度**：梯形或 S 曲线，避免灯头甩动。
5. **预设姿态**：阅读 / 写作 / 氛围 / 收纳。
6. **状态回读**：位置、电流、温度、输入电压，串口输出。
7. **灯环控制**：颜色/亮度/状态；上电默认暖白或关。
8. **OLED 状态页**：角度/电压/温度/当前模式。
9. **失联保护**：总线断线时缓慢卸力，不突然掉落。
10. **WiFi/BLE 遥测**（可选）：上报角度/电流/温度；接收预设。
11. **AI 接口**：串口 CLI 稳定、错误可读、测试脚本可驱动。

> 当前版本**不做**环境光闭环和人体感应；需要换板加传感器，见 §10。

### 5.3 安全

- 30kg·cm 的关节夹手很疼；固件限力矩 + 机械留缝。
- 24 灯环从板载 5V 取电；**40% 亮度是硬上限**，不许做全白、不许改上限。
- 12V 总线加保险丝（5A）或电子熔断；保险丝是防短路，不是防堵转。
- 断电插拔舵机线；带电热插拔可能烧总线。

### 5.4 串口 CLI

命令表与固件要求只维护一份：[course-4h.md §4](../teach/course-4h.md#4-固件-cli教师预烧)。

### 5.5 引脚

| 功能 | 值 |
|---|---|
| 舵机总线 | 板内 UART1，GPIO18=RX，GPIO19=TX，1Mbps |
| OLED | I2C，GPIO21=SDA，GPIO22=SCL，0x3C |
| WS2812 | GPIO23；26 颗（2 板载 + 24 灯环），GRB，800kHz；索引以实测为准；亮度硬上限 40% |
| 输入电压 | 板载 ADC，OLED 显示 |
| 外部 IO | 无排针；只有 1.25mm 3P WS2812 扩展（标 PH1.25） |

## 6. 光源：WS2812 灯环

### 6.1 它是什么 / 不是什么

- **是**：5V 单线可寻址 RGB 灯环；每颗 5050 内置 IC；适合颜色、状态、氛围、动作同步。
- **不是**：高显指阅读灯。白光是 RGB 混出来的，色温/显色/照度都不如 COB。
- 当前课程的目标是「灯光作为状态和视觉反馈」，不是「500lx 阅读照明」。

### 6.2 选型

| 项目 | 选择 | 原因 |
|---|---|---|
| 灯珠数 | **24 灯** | 72mm 外径，10cm 灯罩四周各留约 14mm |
| 电压 | 5V | WS2812B 标准 |
| PCB | 白板 | 反光好，灯罩内更干净 |
| 外径/内径 | 72mm / 54mm | 下单前让客服量 |
| 接口 | SM2.54 3P：输入母座 / 输出公头 | 单灯环只接输入母座，输出公头包好留空；可串下一个 |
| 价格 | ¥4.87 起（24 灯 SKU 约 ¥8–12） | 2026-11 淘宝 |

**不要买**：35 灯（96mm，全白 2.1A，要独立 5V 3A）、37 灯（100mm，装不进）、45 灯（120mm，太大）。
12V WS2815 24 灯可作升级，但要多两根线和一个 12V 分电，当前不选。

### 6.3 供电与数据

- 灯环 5V 从**主控板 1.25mm 3P 口的 5V** 取；24 灯 40% 约 0.58A，板子总电流约 0.78A。
- 共地：5V/GND/DIN 走同一根 3P 线，GND 随线共地。
- 数据：主控板 1.25mm 3P 口的 **OUT（GPIO23）** → 灯环 DIN。
- 24 灯全白约 1.44A；**禁止全白**，固件 40% 硬上限；实测 PH 口低于 4.75V 就降到 30%。
- 数据电平：板载 PH 口按官方设计可直接接 5V WS2812；若闪/乱色，加 74AHCT125。
- 像素偏移：板载 2 颗在扩展口之前；灯环通常从索引 2 开始。代码按 26 颗写，
  用 `test_led` 逐颗点亮验证；不对就改成 24 颗从 0 开始。

### 6.4 光学

- 扩散片：Ø100×2mm 乳白亚克力，离灯环 10–15mm。
- 反光膜：白色 PET 自粘，贴灯罩内壁；橙色内壁会让边缘偏暖。
- 目标：看不到明显单颗灯珠/热点；颜色均匀；灯罩不烫手。
- 24 灯全白 7.2W（40% 约 2.9W），热量远低于 10W COB；不需要铝板散热。

### 6.5 颜色/状态建议

| 状态 | 颜色 | 说明 |
|---|---|---|
| 空闲 | 暖白 (255, 200, 120) | 默认 |
| 运动 | 蓝 (0, 80, 255) | 关节运动时 |
| 示教 | 绿 (0, 255, 80) | 记录/回放 |
| 错误 | 红 (255, 0, 0) | 舵机离线/越界 |
| 关机 | 灭 | `off` |

## 7. 教学模块

建议 8 个实验，每个 1.5–2 小时。

> **只有 4 小时**：重点是 AI agent 写代码 → 走 [course-4h.md](../teach/course-4h.md)；
> 重点是学生动手装配 → 走 [course-4h.md](../teach/course-4h.md)。本文的 8 个实验用于完整学期或课后扩展。

### 实验 0：系统认识与拆装

- 认出各层：结构、舵机、总线、电源、控制、灯光。
- 画一张自己的系统框图，标出「输入/输出/供电/通信」。
- 拆一个关节，观察舵盘、轴承、限位；装回去，确认零位。
- 产出：一张手绘框图 + 一份拆装记录。

### 实验 1：静力学与配重

- 称灯头、上臂、下臂重量，量重心位置。
- 计算三个关节的静态扭矩。
- 用舵机回读电流，对比「无配重 / 有弹簧」。
- 产出：一张「姿态 vs 肩关节电流」曲线。

### 实验 2：三轴运动学

- 量臂长，建立 3R 平面臂模型。
- 用舵机角度计算灯头位置；在纸上画工作空间。
- 验证：给一组角度，卷尺量实际位置，算误差。
- 讨论：奇异点、可达范围、灯头姿态。

### 实验 3：串行总线

- 用板载 Web UI 或 URT-2 扫描 ID。
- 读写位置、速度、力矩、温度、电压寄存器。
- 故意设错 ID/波特率，观察总线表现。
- 产出：一页协议笔记 + 一个能读温度的脚本。

### 实验 4：闭环与重复精度

- 命令阶跃角度，记录实际角度曲线。
- 测重复定位精度和背隙（正反方向各 10 次）。
- 调加速度/力矩限制，观察超调和抖动。
- 讨论：为什么「舵机内部闭环」不等于「系统精度」。

### 实验 5：WS2812 灯环

- 逐颗点亮，确认像素顺序、颜色顺序（GRB）、板载 2 颗与灯环的索引偏移。
- 测 30%/40% 亮度电流和 PH 口电压；确认 40% 上限和板载 5V 余量。
- 对比：裸灯环 vs 加扩散片；橙色内壁 vs 白色反光膜。
- 写 3 个颜色预设 + 呼吸/彩虹效果。
- 产出：一张「亮度 vs 电流/温度」表 + 一段灯光视频。

### 实验 6：系统集成

- 写 4 个预设姿态，带平滑过渡。
- 加软限位、力矩限制、失联保护。
- 把姿态和灯环状态绑定（运动蓝、到位暖白、错误红）。
- 测整机功耗：待机 / 运动 / 灯光。
- 连续跑 30 分钟，记录舵机温度和灯罩温度。
- 产出：一份「整机测试报告」。

### 实验 7：AI 与联网（可选）

- 让 AI agent 按 `hardware.md` 加一个功能（灯环状态/平滑运动/示教）。
- ESP32 开 WiFi/BLE，手机或 PC 连上，读角度/电流/温度。
- 下发一个预设姿态，测「点击 → 动作」的延迟。
- 故意断网/断电，观察重连和失效保护。
- 产出：一个能看遥测、能下发预设的最小上位机。

> 顺序建议：先做 0–6，把本地闭环和灯环做稳；联网是加分项，不是第一天的内容。

## 10. 后续升级（当前不买）

如果以后要加「感知/阅读灯」，当前小 board 没有外部 GPIO，需要换板：

| 目标 | 方案 | 说明 |
|---|---|---|
| BH1750 环境光 / 人体感应 | **General Driver for Robots**（¥145–152） | 板载 IIC/PWM/编码电机口/IMU/INA219 |
| BH1750 / 编码器 / COB PWM | **ESP32-S3 + 灵影 TTL Adapter + 8P Hub**（约 ¥78） | 全 GPIO，4 个模块，接线多 |
| COB 阅读灯 | 12V COB + 恒流/恒压驱动 + MOS | 需换板/独立驱动，当前不做 |
| 更亮的白光 | 12V COB + 扩散片 + 铝板散热 | 需要独立调光/驱动 |
| 手势/姿态交互 | General Driver 板载 9 轴 IMU | 或外接 MPU6050（需 GPIO） |
| 灯环更多效果 | 现有板载 WS2812 扩展口 | 24 灯已限 40%；再串灯环需独立 5V 3A |
