# LT100 硬件资料

这里放“这台机器”的物理资产，不放固件和文档结论。

| 目录 | 内容 | 来源 |
|---|---|---|
| [prints/](prints/) | 14 个已切片的 3MF，直接进打印机 | 本项目结构件 |
| [cad/](cad/) | 微雪主控板 STEP 模型，结构预留空间用 | 官方原件解压，原名见 [reference/README.md](../docs/reference/README.md) |
| [photos/](photos/) | 整机现状照片（正面、侧面） | 本机实拍 |

- 3MF 文件名保留切片的原始编号和中文描述，方便对照打印清单。
- 官方原始压缩包仍在 `docs/reference/`，这里只放工作用的解压件。
- 机械硬限位、配重等结构改动记录在
  [design.md](../docs/design/design.md) 和 [common-platform.md](../docs/design/common-platform.md)。
